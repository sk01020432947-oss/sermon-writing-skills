## 공통 금지 (모든 팩에 붙인다)
템플릿 느낌 · 이유 없는 글로우/파티클 · 3색 초과 · 문구 임의 변경 · 글자 겹침·잘림 · 아무 일 없는 시간

## 이징 기준
- 들어옴: `power3.out` / `expo.out`(애플식)
- 스냅: `back.out(1.6)` (터미널·마스코트)
- UI 스프링: `elastic.out(1, 0.75)`는 쓰지 않는다 — 오버슈트 아주 조금(`back.out(1.2)`)
- 박자: 전환 시각 = 시작 + n × 60/BPM
