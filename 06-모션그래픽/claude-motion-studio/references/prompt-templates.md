# 프롬프트 틀

원본 프롬프트(X 공개 템플릿): 영상2 설명란의 1·2·3번 링크
- https://x.com/himanshutwtxs/status/2103495232637882858 (한 문장)
- https://x.com/twoclipping/status/2103273003555402193 (UI 모핑 구조형)
- https://x.com/twoclipping/status/2103835273813496100 (애플식 런칭)

아래는 영상 화면에서 읽은 구조를 바탕으로 다시 쓴 틀이다. 영어·한국어 둘 다 통한다.

---

## 0단. 사람이 먼저 정할 세 가지
① 어떤 장면을 넣을지(5~12개) ② 박자마다 무엇이 일어날지(BPM·초) ③ 무엇을 금지할지(5개 이상). 셋 중 하나라도 비면 1단(한 문장)으로만 쓰고 결과는 '맛보기'로 다룬다. (영상2 06:53)

---

## 1단. 한 문장 (맛보기)

```
make a dynamic 15-second motion graphics video that shows what an incredible
motion designer you are, like it's your showreel for a résumé. go all out
```
한국어: `이력서에 넣을 쇼릴처럼, 네가 얼마나 대단한 모션 디자이너인지 보여주는 15초짜리 역동적인 모션그래픽 영상을 만들어줘. 전력을 다해.`

한계: 매번 결과가 다르고, 내가 원한 장면이 아니다. 데모용.

## 2단. 4블록 구조 프롬프트 (기본 틀)

```
<inputs>
먼저 나에게 물어볼 것: (1) 화면에 나올 장면/상태 8~12개 (2) 색: 흑백 또는 강조색 1개
(3) 음악: 약 120BPM 저작권 무료 곡(Mixkit 등) — 없으면 네가 고르거나 합성
재료를 받으면 바로 만들지 말고, 박자별 계획표를 먼저 보여주고 승인받아라.
</inputs>

<direction>
<한 줄 콘셉트>. 한 요소가 끊기지 않고 변신한다(컷 없음). 커서가 실제 클릭·드래그로 변화를 일으킨다.
배경 <색>, 요소 <색>, 글꼴 <하나>. 모든 움직임은 스프링, 오버슈트는 아주 조금.
카메라는 각 상태가 화면을 채우도록 확대. 마지막 프레임 = 첫 프레임(루프).
금지: 통통 튀는 이징, 파티클 폭발, 글로우, UI 크롬의 그라데이션, 아이콘 선 두께 불일치,
       아무 일 없는 시간, 템플릿처럼 보이는 모든 것.
</direction>

<structure>
120BPM, 7마디, 매 박자 무언가 일어난다.
버튼 → 로더 → 체크 → 다이내믹 아일랜드 → 음악 플레이어(재생/정지 모핑) → 진행바 스크럽
→ 볼륨 슬라이더(최대 넘겨 끌면 늘어남) → 박자에 토글 → 노브가 탭 표시기로 → 탭이 차트로 열리며 그려짐
→ ⌘K로 접힘 → 타이핑 필터 → 엔터 → 토스트 → 다시 버튼.
</structure>

<build>
1. HTML 한 파일, 정사각 1440x1440(또는 1080). 모든 스타일은 seek(t) 안에서 시간으로 계산.
   CSS transition·타이머·프레임 간 상태 금지.
2. 스프링은 닫힌식 계단 응답. 바뀌는 값은 '스프링 한 번의 합'으로 계산하는 순수 함수.
3. 탭 표시기의 두 모서리는 서로 다른 스프링(앞쪽이 먼저) — 늘어났다 줄어드는 느낌.
4. 드래그는 직접 조작: 커서를 잡은 동안 값은 커서 위치에서 계산, 놓으면 스프링 복귀.
5. 음악을 분석해 박자 격자를 만들고 다운비트에서 시작. UI 소리는 측정된 피크에 맞춘다.
6. Playwright로 렌더, 프레임당 서브프레임 4장을 ffmpeg tmix로 섞어 모션블러, 60fps.
7. 전체 렌더 전에 박자마다 1프레임씩 먼저 뽑아 격자 어긋남·답답함·가독성을 고친다.
</build>

<gotchas>
카메라가 확대하는 요소에 will-change 금지(글자 흐려짐). 모핑 컨테이너 안의 내용 교체가 겹치지 않는지 확인.
</gotchas>
```

> 이 스킬의 렌더러(awesome-ai-motion `render.mjs`)는 30fps·GSAP 타임라인 seek 방식이다. 60fps 모션블러가 꼭 필요할 때만 7번을 따로 구현한다.

## 3단. 스타일 팩 추가 (애플식 런칭)

2단 틀에서 아래만 바꾼다.
```
<inputs> 워드마크용 한 단어 브랜드명(동사가 좋다) / 고해상도 사진 9~12장 /
         드롭과 조용한 브레이크다운이 있는 120BPM 무료 곡 / 식물 그림자가 움직이는 흰 벽 무료 클립(Pexels) </inputs>
<direction> 카메라는 스크린스튜디오처럼 확대해 매 순간이 정사각을 채우고 커서도 함께 커진다.
금지: 크로스페이드, 블러인, '현상되는' 밝기 효과, 3D 플립, 파티클, 글로우, 1초 넘는 정지, 템플릿 느낌. </direction>
<structure> 120BPM, 48박, 매 박자 무언가 일어난다.
열기: 워드마크가 검은 알약으로 압축 → 클릭: 조리개 날 6개가 라벨을 닫았다 사진으로 열림 → 사진 타일이 벤토로 접힘
→ 휴대폰·브라우저 목업 → 벽 그림자 위 액자 → 워드마크 정지. </structure>
```

사진을 '알아서'라고 하면 웹 사진을 임의로 내려받지 않는다. ① 사용자 `source/` ② 무료 라이선스 사진(Pexels 등)은 URL·라이선스를 `source/_출처.md`에 적은 경우만 ③ 없으면 SVG 일러스트로 근사하고 완료 보고에 '일러스트 대체'라고 적는다. (영상2 05:09)

## 4단. 소재 교체 (내 브랜드)

구조·금지목록·build는 그대로 두고 `<inputs>`만 바꾼다. 예:
```
<inputs>
- 워드마크: "KBG Bible Labs"
- 사진 9~12장: 서재 성경, 노트북 코드, 소그룹 모임, 메모 노트
- 120BPM 드롭+조용한 브레이크다운 곡 (Mixkit)
- 책상에서 작업하는 짧은 클립
</inputs>
```

## 영상1식 짧은 지시 (모드별)

| 모드 | 그대로 붙여 쓰는 문장 |
|---|---|
| A 대사+초 | `대사: "<원문>" / 길이 <N>초. 텍스트 없이 모션그래픽으로 만들어줘. 문장마다 의미를 도형·아이콘·차트로 보여주고 타이밍을 대사에 맞춰.` |
| B 참고 영상 | (영상 파일 첨부) `이 레퍼런스를 참고해서 모션그래픽 만들어줘. 스타일·리듬·전환은 그대로, 주제는 "<새 주제>".` |
| C 음악 | (음악·가사 첨부) `이 음악과 가사에 맞춰 모션그래픽을 만들어줘. 가사의 단어가 화면 안에서 실제로 움직이게(spin이면 회전, split이면 분리). BPM <N>.` |
| D 나레이션+이미지 | (나레이션 mp3 + 이미지 6장) `나레이션 문장 시각에 맞춰 <스타일: 종이 찢기 콜라주 / 복스 레트로> 모션그래픽으로. 이미지는 컷아웃 스티커로.` |
| E 광고 | `이 브랜드의 15초 광고를 만들어줘. 콘셉트: <한 줄>. 마지막은 <엔드카드>.` 또는 웹사이트 링크 + `링크 내용 바탕으로 모션그래픽 광고 영상.` 이어서 `세로(9:16)로도.` |

팁(영상1): 레퍼런스는 영상 파일 자체를 올리는 게 가장 좋다. 노력은 '높음' 이상. 길어지면 1시간 넘게 걸린다.

### 자기소개 키네틱 타이포 (쌩초 qi3DHzhUSjs 01:46)
`네가 아는 나에 대한 내용으로 내 소개 모션그래픽을 만들어 줘. 키네틱 타이포(텍스트 중심)에 도형을 섞고, 색은 <2색>+포인트 <1색>. 경쾌한 리듬의 로열티프리 음악(출처·라이선스 기록)을 넣고 모션을 비트에 맞춰. <16:9|9:16>, <N>초.`
- 대화 기록이 적으면 내용 몇 줄을 직접 준다. 공개용 소개 문구는 사실을 확인한다.
- 앞 작업과 섞이지 않게 "이번엔 새로운 작업이야"로 맥락을 끊는다.
