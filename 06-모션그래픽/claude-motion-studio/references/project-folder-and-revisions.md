# 프로젝트 폴더 규약과 초 단위 수정 (영상3)

출처: 쌩초 컴퓨터실 「글만 쓰면 끝! GPT 최신 모델로 모션그래픽 만들기」(youtu.be/Y7l9svE-ymQ, 2026-09-08). Codex 앱에서 한 방식을 이 스킬 흐름으로 옮겼다. 채널 요청: 상업적 강의 커리큘럼으로 그대로 쓰지 말 것.

## 1. 폴더 규약
작업 폴더 하나에 소재를 역할별로 둔다. 그러면 "폴더의 폰트로 바꿔 줘"처럼 짧게 지시할 수 있다.

```
<작업폴더>/
├─ fonts/   Google Fonts 등에서 받은 .ttf/.otf → @font-face로 읽는다(파일명 그대로)
├─ source/  SVG 아이콘·로고·사진 (아이콘은 SVG로 받는다)
├─ music/   음원. 있으면 합성기 대신 이것을 쓴다
└─ output/  v01/, v02/ … 렌더할 때마다 새 번호. 이전 버전은 지우지 않는다
```
- 각 `output/vNN/`에 `clip.mp4`, `check.jpg`(콘택트시트), `change.md`(무엇을 바꿨는지 한 줄)를 둔다. 결과가 이전보다 못하면 번호로 되돌린다.
- Claude 데스크톱 앱에서라면: 채팅창 아래 '프로젝트 또는 폴더' → 새 프로젝트 → 작업 폴더 경로를 붙여 "이 폴더에 작업 시작할게" → 폴더 공유 동의 (쌩초 qi3DHzhUSjs 00:51).
- 링크만 받은 경우(모드 E): 사이트·인스타그램에서 가져온 소재를 `source/`에 저장하고 출처 URL을 `source/_출처.md`에 적는다. 사람 얼굴 사진은 쓰지 않는 것을 기본값으로.

## 2. 프롬프트 최소 다섯 칸 (+비율)
폰트 · 색 · 길이(초) · 분위기 · 소재, 그리고 9:16 또는 16:9. 하나라도 비면 SKILL.md §1 기본값을 쓰고 묻지 않는다. 더 정밀하게는 4블록 구조 프롬프트(prompt-templates.md).

## 3. 초 단위 수정 문법
수정 요청은 한 줄에 **시각 · 대상 · 변화**. 여러 건이면 표로 받아 한 번에 반영하고, 건드리지 않을 것을 '유지'로 적는다.

| 시각 | 대상 | 변화 | 유지 |
|---|---|---|---|
| 3초~ | 'I' 글자 | 흰색으로 | 나머지 색 |
| 전체 | 오른쪽 위 꽃 | 1.2배, 글자 쪽으로 붙임 | 등장 타이밍 |
| 8초 | 로고 | 박히고 2초 정지, 음악 강박과 맞춤 | — |

반영 후 해당 구간만 `?t=<초>`로 정지 화면을 확인하고 새 `output/vNN`으로 렌더한다.

## 4. 레퍼런스 섞기
레퍼런스 한 편을 통째 따라 하지 않는다. 2편 이상을 **구간별·속성별**로 나눠 빌린다(예: 1번의 컷 리듬 + 2번의 색·타이포). 분석은 `watch`로 프레임을 뽑아 "영상 스타일 / 디자인 스타일"을 따로 요약한 뒤 장면 표에 옮긴다.

## 5. 음악 세 갈래
1. 코드 합성(`scripts/` 합성기) — 빠르지만 전자음 느낌.
2. 음악 생성 API — 영상은 '구글 음악 생성 API'라고만 했다. 쓰려면 사용자 키와 요금을 먼저 확인.
3. 무료 음원 — Pixabay Music·Sound Effects(로그인하면 다운로드 오류가 줄어든다). `music/`에 넣고 `audio-post-music` 방식으로 출처·라이선스를 기록.
장면 전환과 로고 착지는 음악의 강박에 맞춘다.

## 6. 무료 소재 출처
- Google Fonts (fonts.google.com) — 대부분 SIL OFL. 폰트별 라이선스 탭 확인.
- Google Fonts Icons / Material Symbols (fonts.google.com/icons) — SVG로 받는다.
- Pixabay Music (pixabay.com/music) — Pixabay 콘텐츠 라이선스 확인, 유튜브 권리 주장 여부는 별도 확인.
- 레퍼런스: Pinterest 'motion graphics'.

## 7. 끝나면 굳힌다
잘 된 결과는 새 스킬을 만들지 말고 `samples/<다음 번호>/`에 index.html·prompt.md(바꿔 쓰기 포인트)·clip.mp4·poster.jpg로 등록하고 SKILL.md 샘플 표에 한 줄 추가한다.
