# 생성 대기열 보드 (Render Queue Board)

## 한 문장 버전
공항 출발 안내판 같은 스플릿 플랩 보드 세 장(RENDER 1회 생성 시간 → PLAN 내 하루 · 쓸 수 있는 시간 → QUEUE 생성 대기열)이 차례로 넘어가며 "영상 한 편 생성에 10분~1시간 30분, 하루 틈에 끼워 넣고, 4편이면 6시간이니 다른 일 하며 기다릴 만하다"를 보여주는 16초 모션을 만들어 줘. 짙은 회색 패널, 미색 글자, 앰버 #F6B60B 한 색 강조.

## 바꿔 쓰기 포인트 (소재만 교체할 자리)
- 패널 A: `text(minT,'010')`, `text(maxT,'130')`, 보조 문구 '10분' '1시간 30분'
- 패널 B: `sched` 문자열(한 시간 2칸, 빈 칸은 공백), 앰버 덩어리 위치 `day.slice(8,12)` 등, 메시지 '여유 시간 활용'
- 패널 C: 줄 이름 '영상0n', 소요 '1:30', 합계 누적 배열, 시계 시작·끝 시각(14:00·36걸음), 메시지 두 개
