# 물방울의 여행 (수채 동화)
원본: 참고 영상 시트 `references/ref-frames/02-watercolor-journey.jpg` · 재현

## 한 문장 버전
종이 결 위 번진 수채 물감으로, 잎 끝에 매달린 눈 달린 물방울이 떨어져 연못 → 강 → 노을 바다(고래) → 증발해 구름 → 눈송이 → 다시 잎으로 돌아오는 16초 순환 동화를 HTML+GSAP로 만들어줘.

## 구조 버전
<inputs>
글자 없음. 1280x720, 16초, 30fps. 주인공: 청회색 물방울(점 눈 2개, 흰 하이라이트, 분홍 볼).
</inputs>
<direction>
- 질감: 종이 노이즈(곱하기 0.55) + 가장자리 비네트. 모든 면은 SVG 필터 `feTurbulence(0.012)+feDisplacementMap(34)`로 테두리를 흔들고, 두 번째 노이즈(0.018)로 안쪽 얼룩(알파 -0.75·1.2)을 낸다. 면은 `mix-blend-mode:multiply`로 겹쳐 물감 층을 만든다.
- 선: 연필 선(1.2~1.5px, #4e6a3a·#3f5a72·#365a91)에 미세 변위(2.2) 필터.
- 색: 하늘 #C7D5D6→#EAD5CF, 잎 #8BAE66, 연못 #5F9E84, 들판 #A6BD7C, 산 #B7A2A6, 바다 #4A8A9C·#2C6578, 노을 #F0BFA0·해 #E8AC74, 구름 #8EA6C2·#A49DBD·#6F88A9, 물방울 #7E9FB8.
- 움직임 동사: 흔들리다, 늘어지다, 똑 떨어지다, 퍼지다(물결), 흘러가다(경로), 떠오르다(김), 그려지다(눈송이), 살포시 앉다.
- 카메라: 장면마다 느린 줌아웃(1.06~1.12→1.0) 또는 옆 패닝, 장면 사이 0.5초 크로스디졸브.
- 금지: 외부 이미지, 채도 높은 원색, 딱딱한 벡터 테두리, 글자.
</direction>

## 원본 대조·보강 기록
- 남은 차이: 원본의 폭포·물속(물고기 떼)·파도 장면은 16초 압축 때문에 빠짐. 연못은 원본의 위에서 본 동심원 연못보다 단순하고, 구름은 원형 얼룩이라 원본의 번진 덩어리감이 약함. 잎·물방울은 원본보다 작음.
- 이번에 바꾼 것:
  - `wash` 필터: 가장자리 흔들림 34→16, 안쪽 얼룩 약화, 안료가 가장자리에 고이는 번짐선(erode 차분) 추가 → 노이즈 덩어리가 아니라 평평한 수채 면으로 보임.
  - 잎→연못: 물방울을 따라 카메라가 내려가는 세로 밀기(S1 위로, S2 아래에서) — 단순 페이드 대체.
  - 바다→구름: 증발 방향대로 S4는 아래로, S5는 위에서 내려오는 밀기.
  - 원본의 '비' 비트 추가(13.0~14.1): 눈송이가 녹아 물방울로 → 빗줄기와 함께 낙하 → 잎으로 매치컷. 눈송이 정지 구간(죽은 화면) 해소.
