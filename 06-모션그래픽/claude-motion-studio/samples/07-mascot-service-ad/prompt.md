# 07 마스코트 서비스 광고 — 빈칸
원본: 참고 영상 07(마스코트 서비스 광고, ref-frames/07-mascot-service-ad.jpg) · 재현형 (가상 예약 서비스 "빈칸")

## 한 문장 버전
흰 바탕에 옅은 파랑 격자, 코발트(#1F4BFF) 큐브 마스코트가 표정을 바꾸며 나레이션을 큼직한 키네틱 헤드라인으로 받아치는 15초 예약 서비스 광고를 1280x720 HTML+GSAP로 만들어줘.

## 구조 버전
<inputs>
나레이션(자막 아닌 큰 헤드라인으로 박기): 0.0 "저기요." / 1.2 "아직도 예약, DM으로 받으세요?" / 3.6 "네일부터 필라테스, 원데이 클래스까지" / 6.2 "빈칸 링크 하나로 바꿔드려요." / 8.0 "딱 3분이면, 예약금·알림·노쇼 관리까지 끝." / 11.0 "사장님은 손님만. 나머진, 저희가." / 13.2 엔드카드 "빈칸 — 일정은 꽉 차게, 손은 가볍게."
소재: 서비스 카드 3장(네일 ₩45,000 / 필라테스 ₩70,000 / 원데이 클래스 ₩58,000), DM 말풍선 3개("내일 2시 돼요?" "가격 얼마예요?" "예약 가능한가요?"), 알림 2개(예약금 입금 완료 / 내일 오후 2시 예약 알림), 폰 예약 화면(달력·시간·예약하기)
비율 1280x720 · 길이 15초 · 무음
</inputs>
<direction>
분위기: 밝고 친근한 SaaS 광고. 색: 흰 #FFFFFF + 격자선 rgba(31,75,255,.07) 40px, 브랜드 #1F4BFF, 남색 #0B1230, 잉크 #0E1220, 배지 빨강 #FF3B30.
글꼴: 헤드라인 Pretendard 900(자간 -0.035em), 강조어(DM·바꿔·3분·저희가·끝·빈칸)는 Gmarket Sans TTF Bold 파랑.
마스코트: 흰 둥근 큐브, 파랑 5px 테두리, 아래로 12px 연파랑 두께(3D 밑면), 왼쪽 위 "26"(달력 칸), 점 눈. 파랑 장면에서는 테두리·밑면을 흰색으로 바꾸고 진한 그림자를 깐다(파랑 테두리가 배경에 묻힘). 표정 3종 — 기본(점 눈+작은 입) / 어지러움(소용돌이 눈+물결 입, "+48" 빨강 배지가 0→48로 카운트) / 행복(^ ^).
움직임 동사: 줄 마스크로 솟기(yPercent 115→0), 튀어나오기(back.out), 밀어 넣기(오른쪽에서 clip-path 와이프), 미끄러져 들어오기(알림), 찍기(도장 "끝." 1.8→1), 깜빡이기, 흔들기.
헤더: 왼쪽 "▣ 빈칸 · 예약 문의", 오른쪽 "2026. 10", 13px. 파랑·남색 장면에서 흰색.
금지: 자막 바 형태, 사진·외부 이미지, 그라데이션 광택, 글자 겹침.
</direction>

## 바꿔 쓰기 포인트 (소재만 교체할 자리)
- 서비스 이름·로고 눈·브랜드 색 `--b`
- 나레이션 6줄(헤드라인 .ln/.w) — 시각은 각 장면 첫 rise 위치 인자
- 카드 3장(아이콘 SVG·이름·가격), 칩 목록, DM 말풍선 문구, 알림 2개, 폰 가게 이름
- 마스코트 숫자 "26"과 표정 순서(face('#fD', t))

## 원본 대조·보강 기록
남은 차이
- 원본 22초 중 '일정은 꽉 차게(블록이 차오르는 비트)'와 82건 달력 전면 비트는 15초 압축으로 생략.
- 원본 파랑 장면엔 헤드라인이 없고 카드만 있음(여기선 카피 유지).
이번에 바꾼 것
- 색을 원본 샘플값으로: 코발트 #0346FF, 어두운 장면 #060B13, 배지 노랑(+99).
- 파랑 진입을 원본 시그니처인 계단 막대 와이프로(아래 줄부터, 마스코트가 기울며 올라탐), 퇴장은 막대가 위 줄부터 빠지며 흰 장면 공개.
- 마스코트→제목 속 미니 로고 매치컷, 남색 장면은 위로 밀어내기(push), 엔드카드는 마스코트 중심 원형 마스크 + 로고 매치컷.
- 줄 마스크 상승 시작점을 140%로 올려 글자 윗부분이 미리 비치던 문제 제거.
