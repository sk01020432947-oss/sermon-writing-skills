# 고양이는 어떻게 집고양이가 됐나 (종이 콜라주 역사)
원본: 참고 영상 시트 `references/ref-frames/04-paper-collage-history.jpg` · 재현(그림은 SVG 원본 드로잉)

## 한 문장 버전
크라프트지 위에 짝짝이 색 글자 타일로 "1만년전"을 붙이고, 나일 들판 배경에 흰 테두리 스티커(쥐·야생 고양이·항아리와 자는 고양이)와 마스킹테이프 손글씨 라벨을 차례로 붙인 뒤, 찢긴 종이 전환으로 밤하늘 "1만년뒤" → 거실 소파 위 고양이로 이어지는 14초 내레이션 싱크 콜라주를 만들어줘.

## 바꿔 쓰기 포인트 (소재만 교체할 자리)
- 내레이션: `.sub` 6줄 + `cue` 배열 시각
- 제목 타일: `#tiles1`/`#tiles2` 글자와 색 클래스(t-red/t-cream/t-teal/t-dark/t-yel/t-pink)
- 스티커 3단계: `#sMice` → `#sCat` → `#sJar` 내부 그림만 교체(예: 양·목자·우리)
- 라벨: `#lMouse` `#lHunter` `#lGuest` 문구
- 결말 장면: `#room` 배경 SVG와 `#guard` 손글씨


## 원본 대조·보강 기록
- 남은 차이: 원본은 사진 같은 일러스트(AI 이미지)라 질감 밀도가 훨씬 높음 — 이 샘플은 SVG 평면 일러스트. 거실 장면의 고양이는 소파 위 쿠션에 얹힌 느낌이 남아 있음.
- 이번에 바꾼 것:
  - 미설치 `Noto Serif KR` → `Nanum Myeongjo`로 교체(대체 글꼴로 렌더되던 문제).
  - 손글씨 글꼴: 기랑해랑 → 나눔손글씨 펜 + 얇은 외곽선(원본의 마커 손글씨에 가까움), 크기 상향.
  - 랜섬 타일 96→124px로 키워 원본 비율에 맞춤, `10,000 YEARS AGO / LATER`를 흑백 교차 오려낸 글자 칩으로 추가(글자별 튀어 붙기).
  - 바구니: 뒤 테두리 → 고양이 → 바구니 앞면 순으로 겹쳐 고양이가 바구니 안에서 고개만 내밀게 함. 천은 얼굴을 덮지 않고 바구니 앞 왼쪽에 걸침.
  - 밤하늘 장면 0.5초 연장(영문 부제 읽힐 시간), 거실 이후 박자 재배치, 마지막 홀드 0.8초 확보.
