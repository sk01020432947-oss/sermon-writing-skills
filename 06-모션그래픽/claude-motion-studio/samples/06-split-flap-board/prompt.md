# 스플릿 플랩 보드 (Split-Flap Board)
원본: "5. 광고 만들기" 단계 소개 영상의 공항 출발 안내판 장면 (ref-frames/06-split-flap-board.jpg) · 재현

## 한 문장 버전
공항 출발 안내판(스플릿 플랩)처럼 글자 타일이 '촤라락' 넘어가며 "01 콘텐츠 운행완료 / 02 재미 운행완료 / 03 실무 고민중"을 띄운 뒤 3행을 "광고 영상 결정"으로 다시 넘기고, 판이 비워지며 신규 노선 판(파란 테두리 2x2 타일 아이콘, "빈칸 · 가상 서비스", 10:00·13:30·16:00·19:30 아래 호박색 예약완료) → 곧 상영 판(NEXT 빈칸 광고, 제작 쉽게 · 속도 바로 · 길이 0:22, 상태 준비중 → 상영 임박)으로 이어지는 16초 모션을 만들어 줘. 브러시드 흑연 패널, 미색 글자, 강조는 호박색 #F5A80A.

## 바꿔 쓰기 포인트 (소재만 교체할 자리)
- 1판: `setRow(행, 번호2칸, 행선지6칸, 상태5칸, 시작초, {dest, stat 색})`
- 2판: `text(name, '빈칸가상 서비스')`, `TIMES` 배열, `'예약완료'`
- 3판: `text(big, '빈칸 광고')`, `fMake`·`fSpeed`·`fLen` 문구, 상태 `'준비중'` → `'상영 임박'`
- 타일은 `line(부모, x, y, 칸수, 너비, 높이, 글자크기)` 한 줄로 어느 판에나 추가
- 머리글 `STEP 05 · …`와 보조 문구 `#foot`
- 칸 수를 늘리면 `DEST`/`STAT` 배열 길이와 `setRow`의 padEnd 수를 함께 조정

## 원본 대조·보강 기록
남은 차이
- 원본 26초를 16초로 압축(장면 사이 홀드를 줄임). 원본의 "실무→광고" 사이 "고민중→제작완료" 같은 중간 상태 일부는 생략.
- 원본 오른쪽 위 브랜드 문구는 "MOTION TERMINAL"로 바꿈(사칭 방지).

이번에 바꾼 것
- 패널·타일을 원본 비율로 키움(패널 1216×540, 타일 72×92, 글자 54px), 칸 묶음 받침판·나사·가로 결 패널 추가, 색을 원본에서 샘플링.
- 3행 "실무 고민중 → 광고 영상 결정" 비트와 행 아래 보조 문구 복원, 완료 행 글자가 회색으로 가라앉는 원본 연출 반영(2판 재넘김 때도 회색 유지).
- 플랩 물리: ease-in 낙하·밝기 감쇠·아래 반쪽 그림자(펼쳐진 뒤 한 프레임 잔류)·정착 튐·경첩 핀, 칸마다 넘김 속도·시작 지터.
- 스크램블 풀 분리: 숫자 칸은 숫자만, 한글 칸은 한글만.
- 램프를 8×3 점으로, 깜빡임 대신 좌→우 빛 흐름.
- 길이 10→11초, 최종 홀드 1.3초.
- (2차) 원본 순서대로 2판 신규 노선(파란 테두리 2x2 아이콘, 빈칸 · 가상 서비스, 예약 시각 4개 + 호박 바탕 예약완료)과 3판 곧 상영(NEXT 빈칸 광고, 제작·속도·길이, 준비중→상영 임박)을 추가하고, 이전의 창작 2판(다음/상태/시간 10:00→13:30)은 뺐다. 길이 11→16초.
- (2차) 엔진을 `line()`/`put()`으로 일반화해 판마다 다른 크기·호박 바탕 타일도 같은 플랩 물리로 넘김. 판 전환 = 빈칸 물결 → 받침판 올라옴, 머리글은 위로 빠지고 아래서 올라옴.
- (2차) 원본에서 14730·4487처럼 보이는 숫자는 넘기는 중의 스크램블이고 정착값은 16:00·19:30이라 그대로 따랐다.
