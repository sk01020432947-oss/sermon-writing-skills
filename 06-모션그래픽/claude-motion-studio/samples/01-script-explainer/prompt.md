# 대본 해설 모션 (Script Explainer)

## 한 문장 버전
이 대본("우리가 항상 사용하는 PPT도 조금씩 조금씩 변화가 있었습니다. 오늘은 아직 많은 분들이 모를 수 있는 기능 세 가지를 알려드리겠습니다. 후딱 지나가니까 집중해주세요.")에 맞춰 11초짜리 글자 없는 모션그래픽을 만들어 줘. 거의 검은 차콜 배경에 주황 #FF6619 하나만 포인트로 쓰고, 슬라이드 편집기 → 사람 아이콘 격자 → 기능 카드 3장 → 가로 빛줄기 → 주황 조준경 순서로.

## 바꿔 쓰기 포인트 (소재만 교체할 자리)
- 박1 "변화" = 슬라이드 내용이 썸네일 순서대로 바뀌는 장면 → 앱 화면 추상화로 교체
- 박2 "많은 분들이 모를" = 사람 격자에서 소수만 남기기(`HOT` 좌표)
- 박3 "N가지" = 카드 수와 아이콘 SVG(벤·레이어·커서), 신호등 점 개수로 순서 표시
- 박4 "집중" = 조준경. 주황 #FF6619 → 브랜드 색 하나로 교체

## 원본 대조·보강 기록
남은 차이
- 원본은 하단 자막이 있으나 이 샘플은 글자 없는 모션만 다룸(의도된 생략)
- 원본 사람 격자는 강조 뒤에도 회색 군중이 잠시 남지만 여기선 바로 사라짐
- 원본 끝(이런 식으로 나옵니다)의 다음 장면 선 그리기는 구간 밖이라 넣지 않음
이번에 바꾼 것
- 사람 → 카드 전환을 매치컷으로: 주황 세 사람이 점으로 줄어 카드 세 자리로 날아가고, 카드가 그 점에서 expo로 펼쳐짐(원본 1:34 무렵 주황 점 씨앗과 같은 구조)
- 카드 등장 이징을 back → expo.out, 0.12초 간격 겹침 동작으로
