# 25 해설 영상 B롤 (Explainer B-roll)
원본: V2(Jay Choi) 6:45–7:45(주로 7:13–7:19), 크리에이터가 해설 사이에 끼운 3초짜리 B롤 컷들 · 재현(러너만 같은 톤으로 보강)

## 한 문장 버전
> 해설 영상 사이에 넣을 3초짜리 모션 B롤 다섯 컷을 만들어줘: 원→사각→오각→삼각→별로 모프하는 색 겹침 도형, CMYK 점으로 된 회전 구, 노란 바탕에서 단어 뜻대로 움직이는 bounce·weight·stretch, 색 분리된 "eases", 잔상을 남기며 달리는 사람.

## 구조 버전
<inputs>
문구: bounce / weight / stretch / eases
비율 1280x720 · 길이 15초(3초 × 5컷, 하드 컷) · 마지막 컷은 0.8초 이상 정지
</inputs>
<direction>
편집 도구 화면 같은 담백한 B롤. 색: 크림 #F5F2EA(점 격자), 노랑 #F7D21E, 핑크 #F04E9A, 주황 #F0461E, 선택 파랑 #2A74E8, CMYK 핑크 #FF3D9A·노랑 #FFE600·하늘 #1E9BFF, 이즈 바탕 노랑 #F5E61B, 주석 파랑 #1F5BFF, 검정 #050506.
글꼴: Pretendard Variable(굵기 100→900 보간), Pretendard Black.
움직임 동사: 돈다·잡힌다·흩날린다·솟는다·그려진다·밀려 들어온다·겹친다·남긴다.
금지: 크로스페이드, 외부 이미지·폰트, 실사 인물(러너는 SVG 선 인형).
</direction>
<structure>
| 초 | 화면 | 움직임 |
|---|---|---|
| 0–3 | A 크림 점 격자 | 주황 도형 뒤로 핑크·노랑이 어긋나 겹치고 얇은 파란 윤곽선이 살짝 늦게 돌며 따라옴. 원(0.1) → 사각(0.75) → 오각(1.2) → 역삼각(1.6) → 별(2.0) → 사각(2.4)으로 모프, 마지막엔 큰 노랑 사각 안에 작은 주황 사각+기울어진 파란 윤곽. 검은 점 3개 공전 |
| 3–6 | B 검정 | 위도 고리로 늘어선 점 구가 3D 회전(극 부근 핑크, 가운데는 노랑·하늘 줄무늬), 깊이에 따라 크기·밝기, 바깥으로 색 눈금이 흩날리고 파란 원 테두리 |
| 6–9 | C 노랑 #F5E61B | 단어마다 1초, 빨강·주황·파랑 세 겹이 시간차로 따라와 색이 갈라짐. bounce: 글자가 위에서 떨어져 튕기고 한 번 더 뜀 / weight: 가는 획(100)이 굵은 획(900)으로 무거워지며 내려앉아 눌림 / stretch: 실처럼 가는 세로선에서 탄성 있게 가로로 늘어남 |
| 9–12 | D 노랑 | "eases"가 오른쪽에서 잔상과 함께 밀려 들어오고 파랑·주황·빨강 세 겹이 어긋났다가 모임(10.8초 한 번 튐), 아래 작은 이즈 곡선이 그려지고 점이 탐 |
| 12–15 | E 검정 | 선 인형 러너가 달리며 주황·파랑 잔상 5개가 시간차로 따라옴(무릎은 뒤로만 굽힘), 14.2초 정지하며 잔상이 몸으로 모이고 홀드 |
</structure>
<build>
HTML 한 파일, GSAP 타임라인 seek, 30fps 렌더, 결정론.
- A 모프: 모든 도형을 둘레 기준 120점으로 다시 샘플링(맨 위 꼭짓점부터)해 점끼리 보간, 레이어마다 오프셋·회전만 다르게.
- B 점 구: 캔버스, 위도 고리 좌표를 Y·X 회전 후 깊이 정렬, 눈금은 Motion.rand(25) 시드.
- C 단어: 같은 단어 세 겹을 서로 다른 지연(0.05초)으로 같은 트윈에 태워 색 분리. weight는 Pretendard Variable의 font-weight 보간.
- D 색 분리: 같은 단어 세 겹(빨강→주황→파랑 순서로 위), 오프셋 값 하나(ch.o)를 줄여 수렴.
- E 러너: 엉덩이·무릎·발, 어깨·팔꿈치·손을 사인 보행 주기로 계산한 폴리라인. 정강이 각 = 허벅지 각 − 굽힘(10–100°로 제한)이라 무릎은 뒤로만 굽는다. 잔상은 같은 함수에 시간 지연(0.07초 간격)을 준 복사본.
</build>

## 바꿔 쓰기 포인트 (소재만 교체할 자리)
- A 도형 순서 `SHP`, 모프 시각 표, 레이어 색(`#pY #pP #pO #pB`)
- B 점 개수 `NP`, 색 `CM`, 회전 속도
- C 세 단어와 단어별 동작(바운스·굵기·늘이기), 레이어 오프셋 `LOFF`
- D 단어("eases" → bounce/weight/stretch 등 원본처럼 교체 가능)
- E 잔상 수 `NG`, 잔상 색, 달리기 속도(`p=tt*11`, `hx` 이동량)

## 원본 대조·보강 기록
대조: V2 7:12–7:20(점→선→타이틀 카드→도형→노란 단어→점 구→회색 토러스).

이번에 바꾼 것
- 컷 순서를 원본대로: 도형(0–3) → bounce·weight·stretch(3–6) → eases(6–9) → 점 구(9–12) → 러너(12–15, 보강).
- 도형 그룹 1.6배(원본: 화면 높이의 약 절반), 점 구 반지름 210→262, 파란 링 330→342.
- 점 구 마지막 0.7초에 원본처럼 토러스로 변형(각 점의 위도·경도를 토러스 좌표로 보간, 기울기 증가), 배경 검정→#8A8A8A, 링·방사선 페이드.
- 컷 전환 판정을 인덱스→섹션 id로 바꾸고, 단어 레이어의 명시적 visible이 다른 컷 위로 새는 버그 차단.

남은 차이
- 원본 첫머리의 점→선→타이틀 카드(제품명 로고 타이포)는 상표라 넣지 않음.
- 원본 bounce는 글자가 아래 위 두 줄로 튀는 배치, 여기서는 한 줄 낙하 후 튀어오름.
