# claude-motion-studio

출처: 피프 「편집 프로그램 없이 모션그래픽 만드는 법 (클로드 오퍼스 5.5)」(youtu.be/wOF1EDpWxQw), Jay Choi 「클로드가 모션그래픽을 정복했습니다」(youtu.be/_kc0riDpxOY). 두 영상의 방법을 하나의 작업 흐름으로 묶고, 기존 스킬과 역할을 나눴다. 보강(영상3): 쌩초 컴퓨터실 「글만 쓰면 끝! GPT 최신 모델로 모션그래픽 만들기」(youtu.be/Y7l9svE-ymQ).

| 단계 | 담당 |
|---|---|
| 무엇을 어떤 순서로 (주문서 문장) | `motion-order-sheet` |
| 어떤 효과로 (637개 카드·레시피) | `awesome-ai-motion` |
| **장면 전체를 코드로 짓고 렌더·음악 합치기** | **이 스킬** |
| AI 이미지 + 파이썬 조립 종이 콜라주(사진 같은 질감) | `vox-paper-motion` |

## 1. 입력 모드 고르기 (영상 1의 5가지 방법)

| 모드 | 사용자가 주는 것 | 이 스킬이 하는 것 | 샘플 |
|---|---|---|---|
| A 대사+초 | 대사 원문, 총 초 | 문장마다 비트를 나눠 "글자 없이" 의미를 도형으로 보여준다 | 01 |
| B 참고 영상 | 영상 파일·URL | `watch`로 프레임을 뽑아 구조·색·리듬만 빌리고 주제는 바꾼다 | 02 |
| C 음악 | 음악 파일·가사, BPM | 박자 격자(60/BPM초)에 장면 전환을 맞춘다. 음악이 없으면 합성한다 | 03, 08, 12 |
| D 나레이션+이미지 | 나레이션 문장별 시각, 이미지 몇 장 | 문장 시각에 맞춰 컷아웃·라벨·전환을 배치 | 04, 05, 14 |
| E 광고 | 나레이션/브리프 또는 웹사이트 링크 | 서비스 정보를 장면으로 옮기고 가로·세로 둘 다 낸다 | 06, 07, 11 |

입력이 비면 기본값: 16:9 1280x720, 12~16초, 30fps, 색 2+배경 1. 묻지 않는다.

## 2. 프롬프트 사다리 (영상 2의 핵심)

1. **한 문장** — 빨리 맛보기. 결과가 매번 달라지고 "내가 원한 영상"이 아니다. → 샘플 08
2. **4블록 구조 프롬프트** — `<inputs>` 재료 / `<direction>` 분위기·색·움직임 + **금지목록** / `<structure>` 박자별 할 일 / `<build>` 구현 규칙. 금지목록이 품질을 가른다(디자인 방향을 안 주면 Claude는 기본 스타일로 돌아간다). → 샘플 09
3. **스타일 팩** — 같은 구조에 요구사항(애플식: 크로스페이드·블러인·3D플립·파티클 금지)을 더한다. → 샘플 10
4. **소재 교체** — 구조는 그대로, 이름·사진·문구만 바꿔 내 브랜드 영상. → 샘플 11

사다리 2~4단 예외: 구조 프롬프트 작업은 §1의 '묻지 않는다' 대신 질문 1회(장면·색·음악) → 박자별 계획표 승인 1회를 둔다. 사용자가 '알아서'라고 하면 '화면은 제시안 그대로 · 색은 흑백+강조 1 · 음악은 합성'으로 채우고 바로 계획표로 간다. '진행' 뒤에는 끝까지 묻지 않는다(영상2 03:43).

틀 원문: [prompt-templates.md](references/prompt-templates.md). 스타일 11종의 색·글꼴·움직임·금지목록: [style-presets.md](references/style-presets.md).

## 3. 작업 순서

1. 모드와 스타일을 정한다. 목적을 한 문장으로 적는다. 작업 폴더는 `fonts/ source/ music/ output/vNN/` 규약을 따르고, 사용자의 수정 요청은 '시각·대상·변화·유지' 표로 받는다 → [project-folder-and-revisions.md](references/project-folder-and-revisions.md).
2. 가장 가까운 샘플 `samples/<NN>/`을 작업 폴더로 복사한다. `prompt.md`의 '바꿔 쓰기 포인트'만 고친다.
3. 새 장면이면 [CONTRACT.md](samples/CONTRACT.md) 골격으로 `index.html`을 짓는다. 장면 표(초·화면·움직임)를 먼저 쓰고 코드로 옮긴다.
   - **스토리보드 관문**(렌더 전, 영상4 쌩초 qi3DHzhUSjs 05:41 · opus A5): 장면마다 대표 시각을 정지 캡처해 시트 한 장으로 보여 준다. 사용자가 장면 번호로 고치고 "렌더"라고 한 뒤에만 4로 간다. 코드 영상이라 시트 그림이 곧 실제 프레임이다.
   ```bash
   for t in 0.5 3 6 9 12; do node ~/DEV/awesome-ai-motion/scripts/shot.mjs "file://$PWD/index.html?t=$t" sb_$t.png 1280 0; done
   ffmpeg -y -pattern_type glob -i 'sb_*.png' -vf "crop=1280:720:0:0,scale=480:-1,tile=3x2" -frames:v 1 check_storyboard.jpg
   ```
4. 렌더:
   결과(clip.mp4·poster.jpg·preview.gif)는 index.html 옆에 저장된다. `--out`을 입력과 같은 폴더로 주면 오류가 난다.
   ```bash
   cd ~/DEV/awesome-ai-motion
   node scripts/render.mjs <작업폴더>/index.html --embed
   ```
5. 납품용 고품질 렌더(1920×1080, 서브프레임 4장 모션블러, `music.wav`가 있으면 자동 합성):
   ```bash
   node ~/.claude/skills/claude-motion-studio/scripts/render_hq.mjs <작업폴더>   # → clip_hq.mp4
   bash ~/.claude/skills/claude-motion-studio/scripts/render_hq_all.sh 6        # 샘플 전체, 동시 6개
   ```
   옵션: `--scale 1.5`(기본, 2면 2560폭) `--sub 4`(블러 서브프레임) `--shutter 0.5`(180° 셔터). 마지막 서브프레임이 정확한 시각이라 정지 화면은 선명하다. 14초 기준 약 3~4분.
6. 검증: 콘택트시트를 뽑아 직접 본다. 빈 화면·글자 겹침·잘림·홀드 부족을 고친다.
   ```bash
   ffmpeg -y -i <작업폴더>/clip.mp4 -vf "fps=1,scale=480:-1,tile=4x4" -frames:v 1 <작업폴더>/check.jpg
   ```
7. 소리: 음악·나레이션이 있으면 합친다(고품질 렌더는 자동). 없으면 `scripts/` 합성기(샘플 03용 `synth_music_94bpm_38s.py`, 샘플 24용 `synth_music_120bpm_run2.py` 등. 맨 위 BPM·길이 상수만 바꿔 씀)로 `music.wav`를 만든다.
   ```bash
   ffmpeg -y -i clip.mp4 -i music.wav -c:v copy -c:a aac -shortest clip_audio.mp4
   ```
8. 비율 변환(광고): `data-size`를 `720x1280`으로 바꾸고 레이아웃을 세로로 다시 배치해 한 번 더 렌더.

## 4. 품질 규칙

- 한 장면 한 초점. 마지막 0.8초 이상 완성 상태를 홀드.
- 시간은 GSAP 타임라인 하나에만. `Math.random`·CSS 애니메이션 금지(렌더가 seek 방식). 난수는 `Motion.rand(seed)`.
- 금지목록을 항상 적는다: 템플릿 느낌, 3색 초과, 이유 없는 글로우·파티클, 문구 바꾸기, 글자 깨짐.
- 통계 수치는 출처 있는 값만, 없으면 화면에 "예시".
- 실존 인물·브랜드 로고·원본 캐릭터는 복제하지 않는다. 구조와 리듬만 빌린다.
- 원본 대조: 각 샘플 `prompt.md` 끝의 「원본 대조·보강 기록」에 남은 차이와 고친 점을 적는다.
- 생성 시간: 영상 1 기준 노력 '높음' 이상에서 10분~1시간 30분. 길이가 늘면 더 걸린다 — 시켜 두고 다른 일을 한다.
