# motion-order-sheet

효과 선택·렌더는 `awesome-ai-motion`이 맡는다. 이 스킬은 그 앞단, **무엇을 어떤 순서로 어떻게 움직일지 적는 주문서**만 만든다.
출처: 김지백 「모션그래픽 주문 사전 88」(nondev-thinking.web.app/motion), 디자인하는AI 「2D 모션그래픽 AI로 만들기」.

## 입력 정리 (없으면 기본값, 묻지 않는다)

| 칸 | 기본값 |
|---|---|
| 목적·보는 사람 | 필수. 한 문장 |
| 화면 비율 | 16:9 (쇼츠·릴스면 9:16, 게시물 1:1) |
| 길이 | 그래픽 1개 4~7초, 인트로 10초 |
| 색 | 브랜드색 2개 + 배경 1개. 없으면 남색 #1F2A44 / 노랑 #F2C14E / 흰 배경 |
| 글꼴 | Pretendard 굵게(제목) / 보통(본문) |
| 내 문구 | 따옴표 안 그대로 쓴다. 띄어쓰기·문장부호 보존 |

## 모드 A — 내용으로 주문서 쓰기

다음 틀을 채운다. "간단히"는 1~3번만, "자세히"는 전부.

```
1. 부르는 말: /hyperframes (Codex는 $hyperframes) 또는 "awesome-ai-motion 레시피 <slug>로"
2. 그래픽 이름: <한글>(<영문>)  예) 예약 단계(booking steps)
3. 길이·비율·해상도: <N>초, 16:9, 1920x1080, 30fps
4. 디자인 규칙: 색 HEX, 글꼴, 격자(여백 8%), 그래픽 요소(선·블록·아이콘)
5. 장면 순서 (초 단위):
   샷1 0.0–1.6s  "<문구>"  등장 방식 / 강조 / 퇴장
   샷2 1.6–3.7s  ...
   마지막 샷  핵심 문구 정지 0.8s 이상
6. 카메라·움직임 공통 규칙: 선택→변형→정렬→출력, 흔들림·과한 회전 금지, ease는 power3.out 계열
7. 소리(선택): 클릭·전환 효과음, 배경음 BPM
8. 하지 말 것: 문구 바꾸기 금지, 추가 로고·워터마크 금지, 글자 깨짐·겹침 금지, 3색 초과 금지
```

규칙
- 장면 순서가 결과를 정한다. 샷마다 시작·끝 초, 문구, 움직임 동사(커진다·밀린다·그려진다·접힌다)를 적는다.
- 여러 그래픽을 이으면 각 주문서 길이를 합친 총 길이를 맨 위에 적는다(주문서 담기).
- 통계 수치는 출처 있는 값만. 없으면 "예시"라고 표시한다.
- 인물·제품·캐릭터가 나오면 "참고 이미지를 생성 단계에서 다시 붙일 것"을 주문서 끝에 적는다(일관성 유지).

## 모드 B — 참고 영상 역분석

1. `watch` 스킬로 프레임+자막을 뽑는다: `--detail balanced` (짧은 클립은 `--start/--end`로 2fps).
2. 프레임을 보고 샷 경계, 샷별 문구·모양·움직임, 전환 방식, 색 HEX 추정, 리듬(BPM 추정)을 표로 적는다.
3. 그 표를 모드 A 틀에 옮기되 **문구·색은 사용자 것으로 교체**하고 움직임 구조만 가져온다.
4. 원본의 로고·캐릭터·고유 일러스트는 복제하지 않는다. 구조와 리듬만 빌린다.
