# 한국어 통제어(STE-K) 글쓰기

출처: ASD-STE100 Simplified Technical English(ASD 관리, asd-ste100.org)의 작문 규칙을 한국어용으로 각색. 한국어 공식 STE 사전은 없다. 어절 기준은 원 규격의 단어 수(절차 20, 설명 25)를 옮긴 근사치다. 국립국어원 '쉬운 공공언어' 원칙과 결합했다.

## 규칙 12

| # | 규칙 | 예 (✗ → ✓) |
|---|------|------------|
| R1 | 한 단어 = 한 뜻. 같은 대상은 끝까지 같은 이름 | 성도/교인/회원 혼용 ✗ → '교인'으로 통일 |
| R2 | 한 문장 = 한 생각(지시문이면 한 동작) | "켜고 확인하고 기록하십시오" → 세 문장 |
| R3 | 문장 길이: 절차·지시 15어절 이하, 설명 20어절 이하 | |
| R4 | 능동태. "~되어지다/~에 의해" 금지 | "점검이 이루어져야 한다" → "담당자가 점검하십시오" |
| R5 | 지시는 명령형(~하십시오/~하세요), 주어를 분명히 | |
| R6 | 명사 연쇄 3개 이하 | "교사 교육 프로그램 운영 계획 수립" → "교사 교육 계획을 세운다" |
| R7 | 조건은 문장 앞에: "~이면, ~하십시오" | |
| R8 | 경고·주의는 짧은 명령으로 시작 + 이유 1문장 | "주의: 송출 전에 음소거를 푸십시오. 소리 없이 방송됩니다." |
| R9 | 어려운 한자어·외래어는 쉬운 말로. 전문어는 처음 한 번 괄호 풀이 | 익일→다음 날, 송부→보냄 |
| R10 | 대명사(이것/그것/해당) 대신 명사를 반복 | |
| R11 | 문단 6문장 이하, 한 문단 한 주제, 핵심 문장을 먼저 | |
| R12 | 순서가 있으면 번호 목록, 없으면 글머리표 | |

## 모드

- **엄격**: R1–R12 모두 적용.
- **80% (기본)**: R1·R2·R4·R6·R9·R10은 엄격, 나머지는 느슨. 설명문·주석 요약·청년부/어르신용 글.
- **절차**: 번호 단계 + 단계당 한 동작 + 필요한 곳에 경고(R8). 맨 위에 "준비물/전제", 맨 끝에 "완료 확인". 봉사자 매뉴얼, 장비 운용.
- **공문**: 핵심 먼저(무엇이 바뀌나 / 누구에게 / 언제부터 / 문의처) + 80% 규칙. 수치는 출처 표기, 출처 없는 수치는 "예시"로 표시.
- **지시서**: AI·사람에게 주는 규칙문. 각 항목을 "명령 1문장 + 이유: 1문장"으로. 의미는 바꾸지 않는다.

## 작업 순서

1. 모드를 정한다(요청에 없으면 80%).
2. 원문의 사실·수치·고유명사·인용을 목록으로 뽑아 둔다(보존 대상).
3. 규칙대로 다시 쓴다.
4. 아래 점검표로 스스로 확인하고, 보존 대상이 모두 남았는지 대조한다.
5. 결과 뒤에 "바꾼 용어 대조표"(원래 말 → 통일한 말)를 짧게 붙인다. 용어를 바꾸지 않았으면 생략.

## 점검표

- [ ] 같은 대상에 다른 이름을 쓴 곳이 없다 (R1)
- [ ] 한 문장에 동작이 둘 이상인 지시문이 없다 (R2)
- [ ] 15/20어절 넘는 문장이 없다 (R3, 80% 모드는 일부 허용)
- [ ] 피동·"~되어지다"가 없다 (R4)
- [ ] 명사 4개 이상 연쇄가 없다 (R6)
- [ ] 경고에 이유가 붙어 있다 (R8)
- [ ] 원문의 사실·수치가 모두 남아 있다

## 하지 않는 것

- 문체를 '자연스럽게·문학적으로' 다듬지 않는다 → korean-humanizer / toego-korean.
- 내용을 보태거나 빼지 않는다. 길이를 줄이는 것은 문장을 나눠서가 아니라 군더더기 표현을 빼서 한다.
