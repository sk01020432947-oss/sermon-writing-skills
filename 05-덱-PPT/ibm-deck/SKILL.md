# IBM Deck — Carbon 기업 발표자료 생성기

IBM Carbon Design System 기반 마케팅 면을 재현하는 스킬. 입력(원고·개요·자료)을 받아
**자체완결 HTML 슬라이드 덱 1개 파일**을 생성한다.

> 이 시스템의 정체성은 **각진 0px 모서리와 그리드 정렬**이다. 둥글게 만들거나 그림자를 넣는
> 순간 다른 기업 덱이 된다. 깊이는 1px 헤어라인과 면색(흰색 → #f4f4f4) 변화로만 만든다.

## 0. 시작 전 확인 (한 턴에 몰아서 질문)

1. **원고/자료** — 없으면 주제만 받아 개요부터 작성해 확인받는다
2. **수치·비교 데이터** — 이 시스템은 표와 카드 그리드가 강하다. 정량 자료가 있으면 미리 받는다
3. **출력** — 화면 발표(기본) / PPTX 변환 / PDF 인쇄

## 1. 스타일 토큰 (절대 변경 금지)

```css
--primary:#0f62fe;   /* IBM 블루. 유일한 브랜드색 */
--blue-80:#002d9c;   /* 눌림 */
--ink:#161616; --ink-muted:#525252; --ink-subtle:#8c8c8c;
--canvas:#fff; --s1:#f4f4f4; --s2:#e0e0e0;
--inv-canvas:#161616; --inv-ink-muted:#c6c6c6;   /* 반전은 마지막 장에서만 */
--hairline:#e0e0e0;
--success:#24a148; --warning:#f1c21b; --error:#da1e28;
```

**색 규칙 (위반 시 스타일 붕괴)**
- **두 번째 브랜드색을 도입하지 않는다.** 파랑 하나다.
- 파랑을 면으로 칠하는 자리는 **CTA 배너 한 종류**뿐이다. 전체에서 1~2회.
- 그림자·분위기 그라디언트를 넣지 않는다. **유일한 예외가 히어로의 옅은 블루 그라디언트**다.
- 차콜(#161616) 반전은 **푸터에서만**. 덱에서는 마지막 장 하나를 푸터로 간주한다.

## 2. 타입 규칙 — 300과 0.16px

| 역할 | 크기(1920 스테이지) | 웨이트 | 자간 |
|---|---|---|---|
| 히어로 h1 | 152px | **300** | -1px |
| 섹션 오프너 h2 | 120px | **300** | -0.8px |
| 서브섹션 h3 | 84px | **300** | 0 |
| 헤드라인 h4 | 64px | 400 | 0 |
| 카드 제목 | 48px | 400 | 0 |
| 리드 | 36px | 400 | 0 |
| 본문 | 32px | 400 | **+0.32px** |
| 보조 본문 | 28px | 400 | +0.32px |
| 캡션 | 24px | 400 | +0.64px |

- 표기 크기는 **원본 웹 토큰 × 2**(히어로 76 → 152px). 자간도 2배다.
- **디스플레이를 굵게 만들지 않는다.** weight 300이 이 브랜드의 목소리다. 숫자도 300이다.
- **본문 자간 +0.16px(덱 +0.32px)를 빼지 않는다.** Carbon의 정밀 디테일이며,
  이걸 빼면 그냥 Helvetica 덱이 된다.
- **eyebrow는 문장형**이다. 대문자에 자간을 벌린 eyebrow는 이 시스템에서 명시적 금지 항목이다.
- **폰트**: IBM Plex Sans는 SIL 오픈폰트라 실물을 그대로 쓴다. **한글도 Plex Sans KR이 있어
  이 덱 계열에서 유일하게 라틴·한글이 같은 서체 가족**으로 맞는다. 대체하지 않는다.

## 3. 그리드

- **16컬럼**(데스크톱) / 8(태블릿) / 4(모바일). 카드 그리드는 **4-up이 기본**이다.
- 템플릿에 그리드 가이드가 들어 있다. **`G` 키로 켜서 정렬을 확인**하고 발표 전에 끈다.
- 좌우 기준선 `--pad`(96px), 섹션 간격 `--sec`(192px), 카드 여백 `--lg`(48px).

## 4. 슬라이드 아키타입 (8종 — 이 중에서만 조합)

| 코드 | 이름 | 배경 | 사용 시점 |
|---|---|---|---|
| I1 | 히어로 | 옅은 블루 그라디언트 | 표지 (그라디언트는 여기서만) |
| I2 | 섹션 오프너 | 흰색 | 챕터 전환 |
| I3 | 카드 4-up | `--s1` | 기능·항목 나열 |
| I4 | 2단 + 패널 | 흰색 | 설명 + 근거(탭·표) |
| I5 | 수치 | 흰색 | 지표 4개 |
| I6 | 파란 CTA 배너 | `--primary` | 선언·강조 (1~2회) |
| I7 | 비교표 | 흰색 | 비교·명세 |
| I8 | 클로징 | `--inv-canvas` | 마지막 장 (반전은 여기서만) |

**리듬 규칙**
- 흰색과 `--s1`(#f4f4f4)을 번갈아 배치해 면 변화로 구간을 나눈다.
- I6(파란 배너)은 챕터 끝에 1~2회. 세 번 이상 나오면 파랑의 신호가 죽는다.
- I8(반전)은 마지막 한 장뿐이다.

## 5. 원고 → 슬라이드 분해 규칙

1. **한 슬라이드 = 한 주장.** 카드는 4개가 기본 단위다(3개면 허전하고 5개는 그리드가 깨진다).
2. 수치는 I5 카드 4-up, 비교는 I7 표. **표에는 가로 헤어라인만** 쓴다.
3. 챕터가 바뀌면 I2, 챕터 끝에 필요하면 I6.
4. 마지막은 I8 반전 + 파란 버튼 하나.
5. 카드 하단의 **→ 화살표**를 유지한다. Carbon 타일의 표식이다.

## 6. 형태 규칙

- **모든 모서리 0px.** 전역 `*{border-radius:0}`이 걸려 있다. 새 컴포넌트도 기본이 0이다.
- **pill 버튼 금지.** 버튼은 사각이고 `min-width:280px`에 라벨 왼쪽·화살표 오른쪽 배치다.
- 버튼을 나란히 둘 땐 **1px 간격으로 붙인다**(Carbon의 버튼 세트 규약).
- 카드 위계는 면색(흰색 → #f4f4f4 → 파랑)과 1px 헤어라인으로만 만든다.

## 7. 모션 규칙 (CSS만)

- 페이드 + 12px 상승, **0.4s**, `cubic-bezier(0,0,.3,1)`, 간격 0.08s. 짧고 기계적으로.
- Carbon의 모션은 장식이 아니라 상태 전달이다. 느린 상승·바운스·글로우 금지.
- `@media print`: 애니메이션 해제, 슬라이드당 1페이지.

## 8. 빌드 절차

1. `template.html`을 골격으로 사용한다 — 토큰·8종 아키타입·그리드 가이드·발표자 노트 포함.
2. 원고를 5장 규칙으로 분해해 **슬라이드 시퀀스 표**(아키타입·배경면·헤드라인·카드 수·수치)를
   먼저 보여준다. **카드가 4의 배수인지, 파란 배너가 2회 이하인지 여기서 확인한다.**
3. `<section class="slide">` 단위로 생성.
4. **발표자 노트**는 `data-note` 속성(HTML 태그 가능, `"` 금지). `S` 토글, 기본 숨김.
5. `{주제}-deck.html`로 저장. **PPTX 변환**은 `../monoline-deck/deck2pptx.py` 공유.
6. **검증**: `G`로 그리드를 켜 정렬을 보고, 첫·중간·마지막 장을 캡처해 점검한다 —
   ① 모서리가 둥글어진 요소가 있는가 ② 디스플레이가 400 이상으로 굵어졌는가
   ③ 본문 자간 +0.32px가 빠졌는가 ④ eyebrow를 대문자로 벌렸는가
   ⑤ 그림자가 생겼는가 ⑥ 반전 장이 마지막 외에 또 있는가.

**함정**
- 한글 파일명은 Edge 헤드리스 캡처가 안 된다. 스크래치패드에 ASCII 이름으로 복사해 찍는다.
  `--user-data-dir`을 새로 주면 Edge 새 탭이 찍히므로 쓰지 않는다.
- **Plex Sans KR에는 weight 300이 있지만 한글은 300에서 매우 가늘어 보인다.** 프로젝터가 어두운
  현장이면 한글 디스플레이만 400으로 올리고 라틴은 300을 지킨다 — 이때도 굵게(600)는 가지 않는다.
- 전역 `border-radius:0`을 풀지 않는다. 원형이 필요하면 그 요소에만 `border-radius:50%`를 준다.

## 9. 조작법 (생성물 안내에 포함할 것)

- `→` / `Space` 다음, `←` 이전, `Home`/`End` 처음·끝, 화면 좌우 클릭·스와이프
- **`S` 발표자 노트 토글**, **`G` 16컬럼 그리드 가이드 토글**(제작 검증용)
- `#3` 해시로 특정 장 직행, `?shot#3`은 캡처 모드
- 브라우저 인쇄(Ctrl+P, 가로)로 PDF 출력
