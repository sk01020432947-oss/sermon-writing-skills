# Neonwire Deck — 네온 와이어 다이어그램 발표자료 생성기

유튜브 테크 해설영상 스타일을 재현하는 스킬. 입력(원고·개요·자료)을 받아
**자체완결 HTML 슬라이드 덱 1개 파일**을 생성한다.

> 이 스타일의 주인공은 글자가 아니라 **선**이다.
> 헤드라인은 작고(48px) 구석에 있고, 화면 한가운데는 비어 있으며,
> 그 빈 곳을 가로질러 선 하나가 **1.15초에 걸쳐 그려지는 동안**이 곧 그 장의 내용이다.
> 정지 화면으로 봤을 때 할 말이 다 되어 있으면 이 스타일을 잘못 쓴 것이다.

출처: `youtube.com/watch?v=WL_qu7l3fgQ` (바이브랩스) 프레임 픽셀 실측.

## 0. 시작 전 확인 (한 턴에 몰아서 질문)

사용자가 이미 밝힌 항목은 건너뛴다:
1. **원고/자료** — 없으면 주제만 받아 개요부터 작성해 확인받는다
2. **b-roll 사용 여부** — 기본은 **없음**(순수 암전). 이 스타일은 사진이 필요 없다.
   기술적 질감이 꼭 필요한 장에만 회로기판·서버랙 사진을 밝기 20%·blur 2px로 깐다
3. **출력** — 화면 발표(기본) / PPTX 변환 / PDF 인쇄

## 1. 스타일 토큰 (실측값 — 변경 금지)

```css
--bg:#080D12;   /* 청기 도는 근사흑. 화면의 88%가 이 색이다. 순검정(#000)·회색 금지 */
--panel:#0D1722; --card:#131E2D; --line:#1E2A3C;
--ink:#F2F5F8;  --dim:#7C8794;   --micro:#4E5A68;
/* 상태 3색 */
--cyan:#1ECCC6;  --amber:#FCA81E;  --red:#FC6C6C;
```

**색 = 상태. 이 규칙이 이 스타일의 전부다.**

| 색 | 뜻 | 쓰는 자리 |
|---|---|---|
| 시안 `#1ECCC6` | 연결됨 · 작동함 · 해결 | 성공 경로, 해답 슬라이드, 살아 있는 노드 |
| 앰버 `#FCA81E` | 문제 제기 · 비용 · 의문 | 엉킨 설정, 결제·API 키, 청중의 반론 |
| 레드 `#FC6C6C` | 차단 · 실패 · 불가 | ⊘, 끊긴 선, NO ROUTE 배지 |

- **darkdoc-deck과 정반대다**: darkdoc은 "슬라이드당 악센트 1색", neonwire는
  **한 장 안에서 색이 바뀌는 것이 메시지**다(앰버로 들어와 시안으로 나간다, 시안이 레드로 꺾인다).
- 그렇다고 세 색을 균등하게 쓰지 않는다. **한 장의 지배색은 하나**,
  나머지 색은 그 지배색이 무엇을 뒤집는지 보여주는 데만 쓴다.
- 상태색이 아닌 곳(중립 노드·비활성 아이콘·배경 격자)은 전부 `--line`/회색이다.
  중립을 상태색으로 물들이면 색의 뜻이 사라진다.
- 네 번째 색을 만들지 않는다. 초록·보라·파랑을 추가하고 싶으면 그건 슬라이드를 쪼갤 신호다.

## 2. 화면 구조 (16:9 / 1920×1080 고정)

```
┌──────────────────────────────────────────────┐
│  ── EYEBROW                                  │  ← left 124px, top 96px
│  헤드라인 48px 볼드                             │
│  보조문장 20px 회색                             │
│                                              │
│              [ .diagram : 1920×700 ]          │  ← top 300px. SVG viewBox와
│              선 · 노드 · 패널 · 스탬프           │     HTML 노드가 같은 px 좌표
│                                              │
│              내레이션 자막 (흰 볼드 30px)        │  ← bottom 52px, 중앙
└──────────────────────────────────────────────┘
```

- **아이브로**: 15px / weight 600 / **자간 .26em** / 대문자 영문. 상태색을 입는다.
  `dash` 클래스를 붙이면 앞에 26px 선이 붙는다. 최대 3단어.
- **헤드라인**: 48px / weight 700 / line-height 1.26. **한 줄이 기본**, 길면 2줄.
  darkdoc(63px)보다 의도적으로 작다 — 크게 키우면 다이어그램이 조연이 된다.
  `<em>`으로 감싼 한 구절만 상태색을 준다(문장 전체를 물들이지 않는다).
- **보조문장**: 20px 회색 한 줄. 없어도 된다.
- **헤더 변형**: `.head.right`(우측 정렬) · `.head.mid`(세로 중앙). 전체의 20% 이하로만 쓴다.
- **자막(.cap)**: 그 장면에서 실제로 말하는 한 문장. 구어체 그대로, 1줄.

### 다이어그램 좌표계

`.diagram`은 1920×700 박스이고, 안의 `<svg viewBox="0 0 1920 700">`와
절대배치 HTML 노드가 **같은 px 좌표**를 쓴다. SVG에서 `(1290, 340)`에 선을 끝냈으면
노드는 `left:1290px; top:281px`(중심 맞추려면 노드 크기의 절반을 뺀다)에 놓는다.

**SVG 경로에는 반드시 `pathLength="1"`을 넣는다.** 길이 계산 없이 `.draw`가 스스로 그려진다.

## 3. 슬라이드 아키타입 (8종 — 이 중에서만 조합)

| 코드 | 이름 | 구성 | 사용 시점 |
|------|------|------|-----------|
| N1 | 흐름 체인 | 노드 → 그려지는 선 → 노드 | A가 B에 닿는다 (가장 자주) |
| N2 | 차단 분기 | 1→2 분기 + ⊘ + `NO ROUTE` 배지 | 길이 막혔다 (레드) |
| N3 | 수렴 | 여러 갈래(앰버) → 한 점 → 명령 한 줄(시안) | 해결 선언 |
| N4 | 상태 반전 | 한 선 안에서 시안이 레드로 꺾인다 | 되던 게 안 된다 |
| N5 | 패널 목업 | 다크 라운드 창(파일트리·코드·표) | 도구 안을 열어 보인다 |
| N6 | 스탬프 | 취소 사선 + 회전 네온 배지 | 수치·조건 한 방 |
| N7 | 말풍선 카드 | 아이콘 + 점선 + 다크 라운드 카드 | 청중의 반론·의문 (앰버) |
| N8 | 칩 스택 | 어긋나게 쌓은 칩 3장 | 목록 · 닫는 장 |

**리듬 규칙**
- 대략 N1 30% : N2·N4 20% : N3·N6 20% : N5 15% : N7·N8 15%.
- **N1을 3연속으로 놓지 않는다.** 같은 좌우 흐름이 반복되면 화면이 멈춘 것처럼 보인다.
  N4(반전)나 N6(스탬프)로 방향을 꺾어 준다.
- **N6 스탬프는 전체에서 두 번을 넘기지 않는다.** 기울임은 `--rot:-8deg` 고정 —
  각도를 키우면 밈이 된다. 취소 사선은 반드시 스탬프보다 **먼저** 등장한다(지우고 나서 새것).
- N7(반론)을 썼으면 **뒤에서 반드시 갚는다** — 점선 앰버로 던진 질문은
  나중 장에서 실선 시안으로 답한다. 갚지 않을 질문은 아예 세우지 않는다.

## 4. 원고 → 슬라이드 분해 규칙

1. **원고를 "상태 전이"로 읽는다.** 이 스타일은 명사가 아니라 **동사**를 그린다 —
   닿는다 / 막힌다 / 꺾인다 / 모인다 / 지워진다. 한 문장에서 전이 동사를 찾아 아키타입을 고른다.
   - "그런데 녀석은 갈 수가 없습니다" → 막힌다 → **N2**
   - "이 문제를 한 줄로 끝냅니다" → 모인다 → **N3**
   - 전이 동사가 없는 문장은 **슬라이드가 아니라 자막**으로만 흘린다.
2. 자막에 원고 문장을 그대로 넣고, 거기서 **명사구 하나**를 뽑아 헤드라인으로 올린다.
   헤드라인은 자막의 요약이 아니라 자막이 가리키는 **상태의 이름**이다.
3. 원고를 **문제 → 반론 → 해결** 3부로 묶고 부마다 지배색을 배정한다:
   문제부=레드/앰버, 반론부=앰버, 해결부=시안. **색이 원고의 진행을 그린다.**
4. 숫자·금액·조건이 나오면 N6 스탬프. 도구 화면을 보여줘야 하면 N5 패널.
5. 표지는 N1 또는 N4, 마지막은 N8(다음 행동)로 닫는다.

## 5. 다이어그램 그리는 법

- **선은 두 개를 넘기지 않는다.** 노드는 셋까지. 넷이 필요하면 장을 쪼갠다.
  이 스타일은 정보 밀도가 아니라 **인과 한 줄**을 위한 것이다.
- 화살촉은 `<polyline>` 3점으로 따로 그리고 `.draw`를 한 박자 늦게 건다(d5, d6).
- 아이콘은 24×24 viewBox의 **선 아이콘만** 쓴다. 채운 아이콘·이모지·PNG 금지.
  로고가 필요하면 단순화한 선 실루엣으로 다시 그린다.
- **스크린샷을 붙이지 않는다.** 도구 화면은 N5 패널로 같은 토큰으로 다시 그린다 —
  스크린샷 한 장이면 화면 온도가 그 자리에서 깨진다.
- 비활성/중립 노드는 `.node.off`(테두리 `--line`, 광 없음, 아이콘 `#8D97A4`)를 쓴다.
- b-roll을 깔 땐 `.bg`에 `--img`만 준다(밝기 20%·blur 2px·26초 켄번스 자동).
  **선이 사진보다 밝지 않으면 그 장은 실패다.**

## 6. 모션 규칙 (CSS만)

- 등장 순서 고정: **아이브로(d1) → 헤드라인(d2) → 보조문장(d3) → 노드(d4~) → 선(.draw) → 자막(d8)**.
  클래스 `in d1`~`d8`(텍스트)과 `pop d1`~`d8`(노드·카드)만 붙이면 된다.
- **선은 항상 노드보다 늦게 그려진다.** 목적지 노드가 이미 있는데 선이 뒤늦게 닿아야
  "도달"로 읽힌다. 반대 순서면 선이 그냥 장식이 된다.
- 신호 발신 노드에는 `.pulse`(2.4초 링 파동 반복)를 건다. 한 장에 하나만.
- `@media print`: 애니메이션 해제·최종 상태 고정·슬라이드당 1페이지.
  단 `transform`은 되돌리지 않는다(스탬프 회전이 살아야 한다).

## 7. 빌드 절차

1. `template.html`(이 스킬 폴더)을 골격으로 사용한다 — 토큰·8종 아키타입·모션·노트·내비가 다 들어 있다.
   예시 슬라이드 8장은 교체용 참조다.
2. 원고를 4단계 규칙으로 분해해 **슬라이드 시퀀스 표**(아키타입·아이브로·헤드라인·자막·지배색)를
   먼저 만들어 사용자에게 보여준다.
3. `<section class="slide" data-note="...">` 단위로 생성. 장 전체를 물들일 땐
   `style="--st:var(--red)"`, 요소 하나만 바꿀 땐 그 요소에 건다.
4. `{주제}-deck.html`로 저장.
5. **검증**: 스크래치패드에 **ASCII 파일명**(`chk.html`)으로 복사한 뒤 헤드리스 캡처한다 —
   한글 파일명은 Edge가 file:// URL을 못 열어 순검정 PNG만 남는다.

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless=new --disable-gpu --window-size=1600,900 --virtual-time-budget=4000 --screenshot="chk1.png" "file:///.../chk.html?shot#1"
```

   점검 항목: ① 중립 노드가 상태색으로 물들었는가 ② 헤드라인이 다이어그램과 겹쳤는가
   ③ 한 장에 선이 3개 이상인가 ④ 자막이 문어체로 딱딱해졌는가.

**이미 밟은 함정 세 개**
- **`.diagram path{stroke:var(--st)}` 를 `.diagram > svg path`로 한정하지 않으면**
  노드·패널 안의 아이콘 SVG까지 상태색에 물든다 — 차단 장의 회색 노드가 통째로 빨개진다.
- **아이콘 광은 도형마다가 아니라 `<svg>` 하나에만 건다.** 도형별 `drop-shadow`는
  아이콘 뒤에 네모난 얼룩을 만든다.
- **회전한 요소에 `pop`을 걸면 회전이 지워진다.** `@keyframes pop`이 `rotate(var(--rot))`를
  물고 있어야 한다. 인라인 `transform:rotate()`는 애니메이션에 덮인다.

## 8. 조작법 (생성물 안내에 포함할 것)

- `→`/`Space` = 다음, `←` = 이전, `Home`/`End` = 처음/끝, 화면 좌/우 절반 클릭도 동일
- `S` = 발표자 노트 토글 (`data-note` 내용이 하단 패널에 뜬다)
- `#N` = N번 슬라이드 바로 열기, `?shot` = 페이지 표시 숨김(캡처용)
- Ctrl+P → PDF 저장 시 슬라이드당 1페이지

## 9. PPTX 변환

monoline-deck 스킬의 변환기를 그대로 쓴다 (`class="slide"` + `?shot#N` 규약 동일, 검증 완료):

```bash
python3 /Users/kbg1023/.claude/skills/monoline-deck/deck2pptx.py "덱파일.html"
```

같은 폴더에 같은 이름의 `.pptx`가 생성된다. 의존성: python-pptx, Edge 또는 Chrome.
