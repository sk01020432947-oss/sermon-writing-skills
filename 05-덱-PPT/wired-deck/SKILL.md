# WIRED Deck — 테크 매거진 에디토리얼 발표자료 생성기

wired.com 지면의 디자인 시스템을 재현하는 스킬. 입력(원고·개요·자료)을 받아
**자체완결 HTML 슬라이드 덱 1개 파일**을 생성한다.

> 원본 스펙의 첫 문장: **"이 웹 표면은 스스로를 SaaS 마케팅 사이트처럼 꾸미기를 거부한다."**
> 이 덱도 마찬가지다. 카드에 그림자를 넣고 모서리를 굴리는 순간 잡지가 아니라 랜딩페이지가 된다.

## 0. 시작 전 확인 (한 턴에 몰아서 질문)

1. **원고/자료** — 없으면 주제만 받아 개요부터 작성해 확인받는다.
   이 스타일은 **글이 길수록 잘 맞는다** — 리드 문단과 본문이 실제로 읽히는 시스템이다
2. **사진** — 기사형 사진(4:5 세로, 3:2 가로)이 있으면 넣는다. 없어도 타이포만으로 성립한다
3. **바이라인** — 글쓴이·날짜·출처 표기를 미리 정한다. 이 시스템은 바이라인이 구성 요소다
4. **출력** — 화면 발표(기본) / PPTX 변환 / PDF 인쇄

## 1. 스타일 토큰 (절대 변경 금지)

```css
--ink:#000;              /* 워드마크·모든 CTA·푸터 채움 */
--ink-soft:#1a1a1a; --body:#757575;
--hairline:#e0e0e0;      /* 기사 행 구분선 */
--canvas:#fff; --canvas-soft:#f5f5f5;
--link:#057dbc;          /* 본문 링크에만. 유일한 유채색 */
```

**색 규칙 (위반 시 스타일 붕괴)**
- **링크 파랑 밖의 유채색 브랜드 악센트를 도입하지 않는다.** 파랑도 본문 링크에만.
- 검정은 워드마크·CTA·푸터의 색이다. 회색 배경을 남발하지 않는다.
- **그림자를 넣지 않는다.** 카드에 소프트 드롭섀도를 다는 것은 명시 금지 항목이다.

## 2. 타입 규칙 — 3서체 체계

| 역할 | 서체 | 크기(1920) | 웨이트 |
|---|---|---|---|
| 커버 헤드라인 | **디스플레이 세리프** | 128px | **400** |
| 섹션 헤드라인 | 디스플레이 세리프 | 96px | **400** |
| 스토리 제목 | 디스플레이 세리프 | 64 / 52px | **400** |
| 카테고리 콜아웃 | 디스플레이 세리프 | 40px | 700 |
| 리드 문단 | **본문 세리프** | 38px | 400 · 행간 1.47 |
| 본문 | 본문 세리프 | 32px | 400 · 행간 1.5 |
| 내비·메타 | **산세리프** | 34 / 28px | 400/700 |
| 바이라인 | 본문 세리프 | 25px | 700 |
| 버튼 | 산세리프 | 32px | 700 · +0.6px |

- 표기 크기는 **원본 웹 토큰 × 2**(커버 64 → 128px).
- **디스플레이 웨이트를 400 위로 올리지 않는다.** 이것이 이 시스템의 가장 강한 금지 항목이다.
  굵은 세리프 헤드라인은 타블로이드지, 400은 매거진이다.
- **읽는 글은 전부 세리프.** 산세리프는 내비·버튼·메타·캡션에만 쓴다(현대 웹의 반대).
- **폰트 대체**: WiredDisplay(고대비 좁은 세리프) → **Playfair Display**,
  BreveText(휴머니스트 세리프) → **Source Serif 4**, Apercu(휴머니스트 산세) → **Inter**.
  한글은 본문 **Noto Serif KR**, UI는 Pretendard. 세리프 디스플레이를 산세로 대체하지 않는다.

## 3. 슬라이드 아키타입 (8종 — 이 중에서만 조합)

| 코드 | 이름 | 구성 | 사용 시점 |
|---|---|---|---|
| W1 | 커버 | 마스트헤드 + 거대 세리프 + 리드 + 바이라인 | 첫 장 |
| W2 | 스토리 행 | 번호 + 제목 + 부제, 헤어라인 구분 | 목차·항목 나열 |
| W3 | 2단 기사 | 좌 본문 / 우 세로 사진 | 본문·설명 |
| W4 | 풀쿼트 | 위아래 2px 규칙선 + 인용 | 인용·강조 |
| W5 | 스토리 카드 3-up | 사진 + 제목 + 부제 (테두리 없음) | 사례 모음 |
| W6 | 데이터 표 | 산세 헤더 + 세리프 수치 | 수치·비교 |
| W7 | 검정 전면 | 반전 밴드 | 챕터 전환 (1~2회) |
| W8 | 클로징 | CTA + 검정 푸터 | 마지막 장 |

**리듬 규칙**
- **마스트헤드 밴드**(워드마크 + 2px 규칙선)를 여러 장에 반복해 지면 감각을 만든다.
- W3(본문)과 W4(인용)를 번갈아 두면 잡지 리듬이 산다.
- W7(검정)은 전체 1~2회.

## 4. 원고 → 슬라이드 분해 규칙

1. **리드 문단을 반드시 쓴다.** 커버에 헤드라인만 놓고 리드를 생략하면 이 스타일이 아니다.
2. 항목 나열은 W2 행 형식(번호·제목·부제)으로. 카드로 감싸지 않는다.
3. 인용·핵심 문장은 W4로 뽑아 규칙선 안에 가둔다.
4. 수치는 W6 표. 헤더는 산세 대문자, 값은 디스플레이 세리프.
5. 마지막은 W8, 검정 푸터로 지면을 닫는다.

## 5. 형태 규칙

- **모든 모서리 0px.** 전역 `*{border-radius:0}`이 걸려 있다. "각진 모서리는 협상 대상이 아니다."
- **원형은 아이콘 컨테이너에만** 허용된다.
- 구분은 선으로 한다: 1px `--hairline`(기사 행), 2px 검정(마스트헤드·풀쿼트).
- 카드에 배경·테두리·그림자를 넣지 않는다. 사진과 활자만 놓는다.

## 6. 모션 규칙 (CSS만)

- 페이드 + 14px 상승, 0.5s, 간격 0.09s. 지면이 넘어가듯 짧게.
- 사진 확대·패럴랙스 금지.
- `@media print`: 애니메이션 해제, 슬라이드당 1페이지. **이 스타일은 인쇄물로도 훌륭하다.**

## 7. 빌드 절차

1. `template.html`을 골격으로 사용한다 — 3서체 토큰·8종 아키타입·마스트헤드·발표자 노트 포함.
2. 원고를 4장 규칙으로 분해해 **슬라이드 시퀀스 표**(아키타입·헤드라인·리드·사진·바이라인)를
   먼저 보여준다. **리드 문단이 있는지, 디스플레이가 400인지 여기서 확인한다.**
3. 사진은 `.photo`/`.shot`에 `--img:url(...)`로 건다.
4. **발표자 노트**는 `data-note` 속성(HTML 태그 가능, `"` 금지). `S` 토글, 기본 숨김.
5. `{주제}-deck.html`로 저장. **PPTX 변환**은 `../monoline-deck/deck2pptx.py` 공유.
6. **검증**: 첫·중간·마지막 장을 캡처해 점검한다 —
   ① 디스플레이 세리프가 700으로 굵어졌는가 ② 모서리가 둥글어졌는가
   ③ 그림자가 생겼는가 ④ 본문을 산세리프로 바꿨는가
   ⑤ 링크 파랑 밖의 색이 들어갔는가 ⑥ 리드 문단을 생략했는가.

**함정**
- 한글 파일명은 Edge 헤드리스 캡처가 안 된다. 스크래치패드에 ASCII 이름으로 복사해 찍는다.
  `--user-data-dir`을 새로 주면 Edge 새 탭이 찍히므로 쓰지 않는다.
- **Playfair Display는 WiredDisplay보다 폭이 넓다.** 원본의 '좁고 키 큰' 인상을 원하면
  히어로에 `transform:scaleX(.94)`를 걸거나 자간을 -2px까지 좁힌다. 과하게 좁히면 가독이 깨진다.
- **Noto Serif KR에는 고대비 디스플레이 컷이 없다.** 한글 헤드라인은 라틴만큼 극적이지 않으므로,
  가능하면 **영문 헤드라인 + 한글 리드** 조합이 원본에 가장 가깝다.
- **원본 행간(커버 0.93)은 라틴 기준이라 한글에서 받침이 윗줄에 물린다.** 템플릿에
  `h1.ko`(1.06) / `h2.ko`(1.14) / `h3.ko·.q.ko`(1.18)를 넣어 두었으니 **한글 헤드라인에는
  반드시 `ko` 클래스를 붙인다.** 영문 헤드라인은 스펙 행간을 그대로 쓴다.

## 8. 조작법 (생성물 안내에 포함할 것)

- `→` / `Space` 다음, `←` 이전, `Home`/`End` 처음·끝, 화면 좌우 클릭·스와이프
- **`S` 발표자 노트 토글** (기본 숨김)
- `#3` 해시로 특정 장 직행, `?shot#3`은 캡처 모드
- 브라우저 인쇄(Ctrl+P, 가로)로 PDF 출력
