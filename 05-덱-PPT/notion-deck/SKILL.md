# Notion Deck — 워크스페이스형 발표자료 생성기

notion.so 마케팅 면의 디자인 시스템을 재현하는 스킬. 입력(원고·개요·자료)을 받아
**자체완결 HTML 슬라이드 덱 1개 파일**을 생성한다.

> 이 스타일의 온기는 **파스텔 틴트 카드**에서 나오고, 무게는 **딥네이비 히어로 밴드**에서 나온다.
> 둘 사이를 흰 캔버스가 이어 준다. 셋 중 하나라도 빠지면 평범한 화이트 SaaS 덱이 된다.

## 0. 시작 전 확인 (한 턴에 몰아서 질문)

1. **원고/자료** — 없으면 주제만 받아 개요부터 작성해 확인받는다
2. **제품 화면** — 워크스페이스·문서·대시보드 스크린샷이 있으면 목업에 넣는다.
   없으면 템플릿 내장 문서 목업(사이드바 + 본문 골격)을 그대로 쓴다
3. **틴트 배정** — 챕터별로 파스텔 틴트를 배정할지, 항목별로 섞을지 정한다
4. **출력** — 화면 발표(기본) / PPTX 변환 / PDF 인쇄

## 1. 스타일 토큰 (절대 변경 금지)

```css
--primary:#5645d4;    /* 보라. 모든 면에서 주 CTA */
--link-blue:#0075de;  /* 링크 전용. 보라와 역할이 다르다 — 섞지 않는다 */
--navy:#0a1530; --navy-mid:#1a2a52;         /* 히어로 밴드 */
/* 스티키 도트 */
--orange:#dd5b00; --pink:#ff64c8; --purple:#7b3ff2; --purple-300:#d6b6f6;
--teal:#2a9d99; --green:#1aae39; --yellow:#f5d75e;
/* 파스텔 틴트 9종 */
--t-peach:#ffe8d4; --t-rose:#fde0ec; --t-mint:#d9f3e1; --t-lavender:#e6e0f5;
--t-sky:#dcecfa; --t-yellow:#fef7d6; --t-yellow-bold:#f9e79f; --t-cream:#f8f5e8; --t-gray:#f0eeec;
--canvas:#fff; --surface:#f6f5f4; --hairline:#e5e3df; --hairline-soft:#ede9e4;
--ink:#1a1a1a; --charcoal:#37352f; --slate:#5d5b54; --steel:#787671;
```

**색 규칙 (위반 시 스타일 붕괴)**
- **보라를 본문 색이나 큰 배경으로 쓰지 않는다.** 큰 면이 필요하면 라벤더 틴트를 쓴다.
- **링크 블루와 보라를 섞지 않는다.** 보라 = 액션, 파랑 = 링크. 한 장에 둘 다 쓰지 않는다.
- 틴트 위 텍스트는 charcoal(#37352f). 순검정으로 바꾸지 않는다.
- `--t-yellow-bold`(#f9e79f)는 **고강조 배너 전용**이다. 일반 카드에 쓰면 강조가 희석된다.

## 2. 타입 규칙

| 역할 | 크기(1920 스테이지) | 웨이트 | 자간 |
|---|---|---|---|
| 히어로 h1 | 160px | 600 | -4px |
| 섹션 오프너 h2 | 112px | 600 | -2px |
| 페이지 헤드라인 h3 | 96px | 600 | -1px |
| 서브섹션 h4 | 72px | 600 | -1px |
| 카드 제목 | 44px | 600 | 0 |
| 부제 | 36px | 400 | 0 |
| 본문 | 32px | 400 | 0 · **행간 1.55** |
| 보조 본문 | 28px | 400 | 0 |
| 대문자 eyebrow | 22px | 600 | **+2px** |

- 표기 크기는 **원본 웹 토큰 × 2**(히어로 80 → 160px). 음수 자간도 2배다.
- 본문 행간 1.55는 이 시스템의 여유를 만드는 값이다. 1.4로 조이지 않는다.
- **폰트**: Notion Sans는 배포되지 않는다. Inter가 그 기반이며 한글은 Pretendard가 받는다.
  스펙의 "generic Inter로 대체하지 말라"는 항목은 실물 폰트를 구할 수 있을 때의 지침이며,
  **웹 덱에서는 Inter + Pretendard가 최선의 근사**다. 이 점을 사용자에게 알린다.

## 3. 슬라이드 아키타입 (8종 — 이 중에서만 조합)

| 코드 | 이름 | 구성 | 사용 시점 |
|---|---|---|---|
| N1 | 네이비 히어로 | 네이비 + 스티키 도트 + 보라 버튼 | 표지 |
| N2 | 섹션 오프너 | 흰 캔버스 + eyebrow + h2 | 챕터 전환 |
| N3 | 파스텔 카드 그리드 | 틴트 카드 3~4장 | **주력** — 항목 나열 |
| N4 | 워크스페이스 목업 | 좌 텍스트 / 우 목업(그림자 허용) | 제품 설명 |
| N5 | 스탯 밴드 | surface 면에 큰 숫자 3~4개 | 지표 |
| N6 | 비교표 | 테두리 + 얕은 행 구분선 | 비교·명세 |
| N7 | 고강조 밴드 | yellow-bold 면 + 배지 + 버튼 | 강조 (1~2회) |
| N8 | CTA 클로징 | surface 배너 + 보라 버튼 | 마지막 장 |

**리듬 규칙**
- **네이비를 연속 두 장 쓰지 않는다.** 이 시스템의 기본 면은 흰색이고 네이비는 사건이다.
  네이비는 표지 + 챕터 하나 정도, 전체에서 2~3회.
- N3(파스텔 카드)이 전체의 30~40%. 한 장에 틴트 네 가지를 넘기지 않는다.
- N7(고강조)은 전체 1~2회.

## 4. 원고 → 슬라이드 분해 규칙

1. **한 카드 = 한 항목.** 카드 제목은 명사구, 본문은 두세 줄.
2. 항목이 5개 이상이면 카드 대신 N6 비교표로 옮긴다.
3. 숫자는 카드에 섞지 말고 N5 스탯 밴드로 뺀다.
4. 챕터가 바뀌면 N2, 챕터 안에서는 N3·N4를 번갈아 쓴다.
5. 마지막은 N8, 보라 버튼 하나로 닫는다.

## 5. 형태 규칙

- **버튼을 pill로 만들지 않는다.** 8px(덱 16px) 모서리다.
  `full` 라운딩은 **배지와 pill 탭 전용**이다.
  > 원본 개요는 CTA를 "purple pill"이라 부르지만, 컴포넌트 스펙(`button-primary` = rounded md)과
  > 금지 항목("Do not render pill-shaped buttons")이 8px를 지시한다. **더 구체적인 쪽을 따랐다.**
- 라운딩 사다리: 배지 `--r-sm` → 버튼·입력 `--r-md` → 카드 `--r-lg` → 대형 패널 `--r-xl`.
- **그림자는 워크스페이스 목업에만.** `rgba(15,15,15,.2) 0 24px 48px -8px`(덱에서는 2배).
  문서 카드·기능 카드에는 넣지 않는다.
- 스티키 도트는 5~7개, 크기를 섞어 흩뿌린다. 정렬하면 장식이 아니라 정보로 읽힌다.

## 6. 모션 규칙 (CSS만)

- 페이드 + 18px 상승, 0.65s, 간격 0.10s. 가볍고 다정하게.
- 도트는 정지시킨다. 떠다니게 만들면 산만해진다.
- `@media print`: 애니메이션 해제, 슬라이드당 1페이지.

## 7. 빌드 절차

1. `template.html`을 골격으로 사용한다 — 토큰·8종 아키타입·도트·문서 목업·발표자 노트 포함.
2. 원고를 4장 규칙으로 분해해 **슬라이드 시퀀스 표**(아키타입·배경·틴트·제목·본문)를 먼저 보여준다.
   **네이비 연속 여부와 틴트 중복을 이 표에서 확인한다.**
3. `<section class="slide">` 단위로 생성. 목업 이미지는 `.mock .body`에 `--img`로 건다.
4. **발표자 노트**는 `data-note` 속성(HTML 태그 가능, `"` 금지). `S` 토글, 기본 숨김.
5. `{주제}-deck.html`로 저장. **PPTX 변환**은 `../monoline-deck/deck2pptx.py` 공유.
6. **검증**: 첫·중간·마지막 장을 캡처해 점검한다 —
   ① 버튼이 pill이 됐는가 ② 보라가 본문·큰 배경에 새어 들어갔는가
   ③ 링크 블루와 보라가 한 장에 같이 있는가 ④ 카드에 그림자가 생겼는가
   ⑤ 네이비가 두 장 연속인가 ⑥ yellow-bold를 일반 카드에 썼는가.

**함정**
- 한글 파일명은 Edge 헤드리스 캡처가 안 된다. 스크래치패드에 ASCII 이름으로 복사해 찍는다.
  `--user-data-dir`을 새로 주면 Edge 새 탭이 찍히므로 쓰지 않는다.
- 파스텔 틴트는 **프로젝터에서 흰색으로 날아갈 수 있다.** 밝은 회의실 발표라면 틴트 카드에
  1px `--hairline` 테두리를 되살려 형태를 잡아 준다(템플릿의 틴트 클래스는 테두리를 지운다).
- `.dots i`는 절대 위치다. 텍스트 뒤로 가야 하므로 `.slide > *:not(.dots)`의 `z-index:1`을
  건드리지 않는다.

## 8. 조작법 (생성물 안내에 포함할 것)

- `→` / `Space` 다음, `←` 이전, `Home`/`End` 처음·끝, 화면 좌우 클릭·스와이프
- **`S` 발표자 노트 토글** (기본 숨김)
- `#3` 해시로 특정 장 직행, `?shot#3`은 캡처 모드
- 브라우저 인쇄(Ctrl+P, 가로)로 PDF 출력
