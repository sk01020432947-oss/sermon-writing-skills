# Nike Deck — 스포츠 캠페인형 발표자료 생성기

nike.com의 디자인 시스템을 재현하는 스킬. 입력(원고·개요·자료)을 받아
**자체완결 HTML 슬라이드 덱 1개 파일**을 생성한다.

> 원본 스펙의 원칙 그대로: **"사진이 말하고, 크롬은 말하지 않는다."**
> 캠페인 히어로는 거대한 대문자 락업으로 소리치고, 나머지 화면은 회색과 검정으로
> 완전히 입을 다문다. 이 **극단적 대비**가 시스템 전체다.

## 0. 시작 전 확인 (한 턴에 몰아서 질문)

1. **원고/자료** — 없으면 주제만 받아 개요부터 작성해 확인받는다
2. **사진** — 이 시스템은 **사진이 논증**이다. 캠페인용 가로 사진 2~3장은 있어야 한다.
   없으면 템플릿의 어두운 그라디언트가 대신하지만, 사진 없는 나이키 덱은 절반만 작동한다
3. **세일/수치 데이터** — 빨강을 쓸 수 있는 유일한 자리가 가격 행이다
4. **출력** — 화면 발표(기본) / PPTX 변환 / PDF 인쇄

## 1. 스타일 토큰 (절대 변경 금지)

```css
--ink:#111;              /* CTA의 검정. 근사흑 회색으로 바꾸지 않는다 */
--canvas:#fff; --cloud:#f5f5f5;   /* 제품 사진 배경은 이 회색 */
--charcoal:#39393b; --ash:#4b4b4d; --mute:#707072; --stone:#9e9ea0;
--hairline:#cacacb; --hairline-soft:#e5e5e5;
--sale:#d30005;          /* 가격 행에만. 배경으로 절대 쓰지 않는다 */
--success:#007d48; --info:#1151ff;
/* 카테고리 악센트 — 주 크롬에 쓰지 않는다 */
--pink:#ed1aa0; --purple-soft:#beaffd; --teal:#0a7281;
```

**색 규칙 (위반 시 스타일 붕괴)**
- **세일 빨강은 가격 행에만.** 배경·배너·카드 채움에 쓰지 않는다.
- 카테고리 악센트(핑크·퍼플·틸)를 **주 크롬(버튼·내비·카드)에 배치하지 않는다.**
- **CTA의 검정을 근사흑 회색으로 바꾸지 않는다.** #111이다.
- 소매 크롬의 유일한 색 신호는 세일 빨강과 성공 초록뿐이다.

## 2. 타입 규칙 — 극단적 대비

| 역할 | 크기(1920 스테이지) | 웨이트 | 행간 |
|---|---|---|---|
| **캠페인 락업** | **192px** | 500 | **0.9** · 대문자 |
| 섹션 헤더 | 64px | 500 | 1.2 |
| 서브섹션 | 48px | 500 | 1.2 |
| 카드 제목 | 32px | 500 | 1.75 |
| 본문 | 32px | 400 | 1.5 |
| 캡션 | 28px | 500 | 1.5 |
| 미세 법적 문구 | 18px | 500 | 1.75 |

- 표기 크기는 **원본 웹 토큰 × 2**(캠페인 96 → 192px).
- **96px 락업은 캠페인 히어로 전용**이다. 일반 섹션에 쓰면 시스템이 무너진다.
  예외는 선언 슬라이드(N7) 하나뿐이며 전체에서 1회.
- 이 시스템에는 **700 굵기가 거의 없다.** 대부분 500이다 — 대비는 굵기가 아니라 크기와 사진이 만든다.
- **폰트**: Futura ND·Helvetica Now는 사유 폰트다. 지오메트릭 대체로 **Jost**(Futura 계열),
  UI는 Inter, 한글은 Pretendard. 한글에는 푸투라의 기하학적 인상이 없으므로
  **영문 락업을 쓸 수 있으면 영문으로 두는 편이 원본에 가깝다.**

## 3. 슬라이드 아키타입 (8종 — 이 중에서만 조합)

| 코드 | 이름 | 구성 | 사용 시점 |
|---|---|---|---|
| N1 | 캠페인 히어로 | 풀블리드 사진 + 락업 + 좌하단 흰 pill | 표지 |
| N2 | 캠페인 타일 2분할 | 큰 타일 1.7 : 작은 타일 1 | 두 주제 |
| N3 | 제품 카드 그리드 | 여백 0·라운딩 0 카드 + 칩 필터 | **주력** — 항목 나열 |
| N4 | 2단 + 멤버 카드 | 좌 텍스트 / 우 어두운 사진 카드 | 사례·프로그램 |
| N5 | 수치 | 락업 크기 숫자 4개 | 지표 |
| N6 | 공시 행 | 24px 여백 + 헤어라인 | 명세·비교 |
| N7 | 선언 | 검정 면 + 락업 | 전환 (1회) |
| N8 | 클로징 | 검정 pill + 4열 푸터 | 마지막 장 |

**리듬 규칙**
- **48px(덱 96px) 섹션 리듬**으로 쌓고, 사진의 블리드 가장자리 자체를 구분선으로 쓴다.
- **같은 스케일의 캠페인 타일 두 장을 한 행에 놓지 않는다**(스펙 금지). N2는 1.7:1로 어긋나 있다.
- **검정 pill은 뷰포트당 하나.** 짝은 soft-cloud 보조 버튼뿐이다.

## 4. 원고 → 슬라이드 분해 규칙

1. **캠페인 문장은 3~5단어.** 락업은 두 줄까지다. 설명은 아래 본문으로 내린다.
2. 제품·항목은 N3 카드 4-up. 카드 안에 문단을 넣지 않는다(제목·메타·가격 각 한 줄).
3. 수치는 N5에서 락업 크기로 키운다. 단위는 캡션으로 내린다.
4. 챕터 전환이 필요하면 N1(사진)이나 N7(검정 면) 중 하나. 둘을 연달아 쓰지 않는다.
5. 마지막은 N8, 검정 pill 하나.

## 5. 형태 규칙

- **버튼은 pill(30px, 덱 60px) 아니면 원형 아이콘.** 세 번째 형태를 만들지 않는다.
- **제품 카드는 여백 0·라운딩 0**, 사진이 카드 끝까지 나가고 메타는 사진 아래 8px 간격.
- **그림자·카드 엘리베이션 금지.** 깊이는 사진이 만든다.
- **밑줄은 링크와 활성 내비에만.** 다른 요소에 밑줄을 긋지 않는다.
- 온이미지 CTA는 **흰 pill을 좌하단**에 앵커한다.

## 6. 모션 규칙 (CSS만)

- 페이드 + 24px 상승, 0.55s, 간격 0.10s. 텍스트만 든다.
- **사진은 정지한다.** 켄번스·패럴랙스를 넣지 않는다 — 이 시스템의 사진은 포스터다.
- `@media print`: 애니메이션 해제, 슬라이드당 1페이지.

## 7. 빌드 절차

1. `template.html`을 골격으로 사용한다 — 토큰·8종 아키타입·스와치·발표자 노트 포함.
2. 원고를 4장 규칙으로 분해해 **슬라이드 시퀀스 표**(아키타입·사진·락업 문구·CTA)를 먼저 보여준다.
   **락업이 캠페인/선언 외에 쓰이지 않는지, 검정 pill이 장마다 하나인지 확인한다.**
3. 사진은 `.campaign`·`.tile`·`.shot`·`.member`에 `--img:url(...)`로 건다.
4. **발표자 노트**는 `data-note` 속성(HTML 태그 가능, `"` 금지). `S` 토글, 기본 숨김.
5. `{주제}-deck.html`로 저장. **PPTX 변환**은 `../monoline-deck/deck2pptx.py` 공유.
6. **검증**: 첫·중간·마지막 장을 캡처해 점검한다 —
   ① 락업을 일반 섹션에 썼는가 ② 세일 빨강이 배경에 칠해졌는가
   ③ 그림자가 생겼는가 ④ 제품 카드에 여백·라운딩이 들어갔는가
   ⑤ 같은 크기 캠페인 타일이 나란히 있는가 ⑥ 검정 pill이 한 장에 둘 이상인가.

**함정**
- 한글 파일명은 Edge 헤드리스 캡처가 안 된다. 스크래치패드에 ASCII 이름으로 복사해 찍는다.
  `--user-data-dir`을 새로 주면 Edge 새 탭이 찍히므로 쓰지 않는다.
- **Jost는 Futura의 근사이지 대체가 아니다.** 특히 대문자 R·a·t의 인상이 다르다. 원본 느낌이
  중요하면 락업만 이미지로 만들어 넣는 편이 낫다.
- **한글 락업은 행간 0.9에서 받침이 윗줄에 붙는다.** 템플릿에 `.lockup.ko`(행간 1.02)를 넣어
  두었으니 한글 문구에는 반드시 `ko` 클래스를 붙인다. 영문 락업은 0.9 그대로 둔다.

## 8. 조작법 (생성물 안내에 포함할 것)

- `→` / `Space` 다음, `←` 이전, `Home`/`End` 처음·끝, 화면 좌우 클릭·스와이프
- **`S` 발표자 노트 토글** (기본 숨김)
- `#3` 해시로 특정 장 직행, `?shot#3`은 캡처 모드
- 브라우저 인쇄(Ctrl+P, 가로)로 PDF 출력
