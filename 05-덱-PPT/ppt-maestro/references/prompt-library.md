# 검증된 프롬프트 14선 (영상 출처)

`{}` 부분만 바꿔 재사용. 한국어 그대로 써도 되고, 이 스킬이 내부적으로 python-pptx 작업 지시로 번역한다.

## 생성·스펙

1. **빈 템플릿 오토필** (OFFICE MASTER)
   > 첨부 양식에 맞춰 스킬을 사용해 문서를 작성해 주세요. 주제는 {한국은행 신입 행원을 위한 4시간 커리큘럼}. 커리큘럼에 1~4 모듈명을 구체적으로 기술. 강사명은 {홍길동}으로 변경. 강의 이력은 주제에 맞게 회사명과 주제를 임의로 작성.

2. **유사 내용 템플릿 업그레이드** (OFFICE MASTER)
   > 첨부 양식에 맞춰 PPTX 작성. 1. 교육 세부 파트는 {A, B, C}. 2. 전체 텍스트 수준을 첨부 양식보다 더 세련되고 전문적인 용어·문장으로 작성.

3. **이질 템플릿 재활용** (OFFICE MASTER)
   > 스킬을 사용하여 첨부 파일의 각 슬라이드 구조를 분석하여 1. 각 장표를 {삼성화재 애니카 손해사정 전략파트 대리급} 업무 시나리오에 맞춰 2. 가장 적합한 임의 주제로 슬라이드를 작성해 주세요.

4. **슬라이드 인벤토리 표** (OFFICE MASTER)
   > 도출된 결과의 슬라이드 분석 표를 작성해 줘. 1. 목적: 주제를 입력하면 적합한 슬라이드를 추천받으려고 함. 2. 표 구조: 파일명, 슬라이드 번호, 슬라이드 유형, 비주얼 구조 요약, 주요 도형, 교체 텍스트 수, 적합한 주제 키워드, 부적합한 주제, 교체 시 주의사항, 완성 예시 주제.

5. **커스텀 스킬 → 우리 회사 스킬** (우석지니)
   > 첨부한 {A4 세로형 이슈브리프} PPTX 자동 생성 스킬 md와, 실제 스킬 적용 결과 샘플 PDF를 참고해 줘. 작성한 브랜드 스펙에 맞게 우리 회사 전용 스킬로 변환해 줘.

6. **표준 PPTX → 스킬 추출** (우석지니)
   > 업로드한 표준 슬라이드 PPTX에서 표지와 목차를 제외한 나머지를 분석해 스타일시트와 레이아웃 프롬프트를 담은 스킬 md를 만들어 줘.

7. **PDF → 스킬 → 샘플** (우석지니)
   > PDF를 올릴 테니 분석·추출해서 스킬을 만들고, 그 스킬로 샘플 PPTX를 만들어 줘. (정확도: PDF > PPTX > HTML)

8. **스타일시트+프롬프트 템플릿** (우석지니, 클로드 in PPT)
   > 지금 만든 {49}페이지가 완성본이야. 스타일 시트로 추출·작성해서 다음에 재사용할 수 있게 알려주고, 프롬프트 템플릿을 작성해서 새 페이지 하나를 만들어 줘.

9. **NotebookLM 커스텀 슬라이드 정련어** (우석지니)
   > 완전한 흰색 배경, 격자·그라디언트 없이, 벡터·플랫·솔리드 컬러. 메인 컬러는 #{0013D7}, 서브는 #{032604} (액센트로 사용). 문장 끝에 마침표 찍지 말 것. 픽토그램과 데이터 시각화 인포그래픽으로 깔끔하고 세련되게. 15페이지 이하 파트로 분할 생성.

## 수정·리페어

10. **오탈자 일괄 검수** (오빠두엑셀)
    > 모든 슬라이드에서 오탈자가 있는지 검토한 후, 오탈자가 있으면 찾아서 수정하세요. (차트 내 텍스트 포함)

11. **안전 번역** (오빠두엑셀)
    > 현재 선택한 슬라이드를 복제한 후, 복제한 슬라이드의 모든 텍스트를 영어로 번역합니다. (원본 보존)

12. **텍스트 → 시각화** (오빠두엑셀·피프)
    > {N}번 슬라이드의 내용을 시각적으로 변환하세요. 각 항목에 변환 전 수치·변환 후 수치·증가율이 시각적으로 강조되도록. / {N}번 슬라이드 텍스트를 {카드형 | 순서 있는 프로세스 흐름 | 차트}로 바꿔 줘.

13. **병합·분할·리디자인** (피프)
    > {6}번과 {7}번 슬라이드를 합쳐 한 장으로 만들어 줘. / {5}번 슬라이드를 두 페이지로 나눠 줘. / 전체적으로 너무 평범함 — {모던 에디토리얼} 스타일로, 강조는 {Pretendard Black}, 본문은 {Pretendard Medium}, 차트와 내용이 조화되고 전달이 명확하게 재배치.

14. **엑셀 연동 차트 슬라이드** (피프)
    > 열려 있는 엑셀의 {분기별 매출} 시트에서 {사업부별 합계} 데이터를 가져와 {사업부별 분기 매출 추이 꺾은선} 차트 슬라이드를 만들어 줘.

## HTML 덱 루트용 (화면 발표 전용일 때)

- 디자인 기준 4종을 먼저 고정: 폰트(눈누 링크), 컬러 4색(배경/메인/서브/텍스트), 비율(16:9 중앙 꽉 차게 + 창 크기 변해도 비율 유지 확대축소), 레퍼런스 이미지(레퍼런스1·2·3으로 개명 후 "레퍼런스1처럼 아이콘 단순하게" 식으로 지목). (헤이디)
- 본문 2장만 먼저 디자인 → 마음에 들 때까지 수정 → "이 2장을 기준으로 나머지 전체 디자인". (헤이디)
- 대본 첨부 후 "대본 흐름에 맞춰 애니메이션. 엔터를 치면 다음 요소가 나오게". (헤이디)
