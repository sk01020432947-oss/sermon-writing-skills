# BRAND-SPEC.md 양식

샘플(PDF 권장)에서 추출해 아래를 채운다. 모르는 값은 사용자에게 1회 질문으로 묶어서 확인.

```markdown
# 브랜드 스펙 — {회사/조직/개인 이름}

## 기본
- 조직명(헤더 표기): 
- 로고: {파일 경로 | 텍스트 로고 문구}
- 문서 유형: {임원 보고 | 제안서 | 강의안 | 홍보 | ...}
- 판형: {16:9 | A4 세로 210×297mm}

## 컬러 시스템 (HEX 필수)
- 메인: #
- 서브: #
- 액센트 1: #
- 액센트 2: #
- 대비(글자/배경): #1A1A1A / #FFFFFF
- 전략: {블루톤 직행 | 웜그레이 메인 + 브랜드색 액센트}

## 타이포그래피
- 제목: {폰트} {크기pt} {굵기}
- 본문: {폰트} {크기pt}
- 캡션/헤더·푸터: {폰트} {크기pt}
- 영문 전용 폰트(있으면): 

## 레이아웃 규칙
- 상단: 섹션 탭(브레드크럼) — 현재 위치 표시
- 헤더: {조직명 좌 | 로고 우}, 푸터: {문서명 + 페이지 넘버, 작게}
- 거버닝 메시지(리드 문구): {위치 — 좌측 세로 | 제목 하단 가로}
- 여백 원칙: 상+좌만 막고 우측은 본문 자유 영역 (상하좌우 다 막지 말 것)

## 유형 정의 (최소 3종)
- 표지: {구성}
- 본문 A(텍스트형): {구성}
- 본문 B(차트/비교형): {구성}
- 결론: {구성}

## 금지·주의
- 그라디언트/격자/복잡 배경 금지(수정 불가능해짐), 완전한 흰색 배경
- 문장 끝 마침표 {찍음 | 안 찍음}
- 텍스트는 실제 텍스트 박스로(이미지 글자 금지)
```

## 문서 3원칙 (검수 기준)

1. 가독성 우선 — 잘 읽히고 잘 보이는가
2. 서식 일관 — 위치·폰트·컬러가 전 장에서 동일한가
3. 아이덴티티 — 우리 조직 느낌이 나는가
