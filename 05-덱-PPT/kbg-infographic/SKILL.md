# kbg-인포그래픽 — 자료를 학회 포스터 한 장으로

설교·논문·강의안 하나를 받아 [template.html](template.html)의 레이아웃으로 1400px 폭 포스터를 만든다.
템플릿은 누가복음 7:36–50 설교 예시로 채워져 있다 — 구조와 클래스를 그대로 두고 내용만 갈아 끼운다.

## 절차

1. **원문 읽기.** 파일 전체를 읽는다(hwp/hwpx는 kordoc·read-hwp, pdf는 pdf 스킬). 원문에 없는 숫자·인용은 만들지 않는다.
2. **뼈대 뽑기** — 아래 7칸을 먼저 채운 뒤 HTML로 간다.
   | 칸 | 설교 | 논문 |
   |---|---|---|
   | 제목(질문형) | 본문이 던지는 질문 | 연구 질문 |
   | 배지+부제 | 본문 장절 + 주제 한 줄 | 약칭 + 부제 |
   | 히어로 큰 숫자 1개 | 본문 속 숫자·대비(500:50 등) | 헤드라인 결과(11.7% 등) |
   | 히어로 지표 3개 + 대조 목록 | 인물·행위·선언 / ✗○ 대조 | 세 지표 / 그룹별 수치 |
   | TL;DR 한 문장 | 설교의 한 문장 | 초록의 한 문장 |
   | 섹션 4–6개 | 문제·구조·해석·적용 | Problem·Method·Benchmark·Results |
   | 기억할 것 3개 + 범위/출처 | 결단 3개 | Takeaways + Limitations·Cite |
3. **컴포넌트 고르기** (섹션마다 1–2개, 같은 것 3번 연속 금지)
   - `.steps` 번호 원형 리스트 · `table`(`tr.me`로 내 항목 강조) · `.formula`+`.def` 정의/공식 박스
   - `.bars` 가로 막대(값·근거 열) · `.callout` 큰 숫자 한 줄 · `.vs` 기대 vs 실제
   - `.grid3 .card.soft` 적용 카드 3개 · `.chips` 관련 구절/키워드 · `.card.alert` 점선 경고 박스
   - 막대 폭은 `style="width:NN%"`로 실제 비율대로.
4. **분량 맞추기.** 좌우 단 높이가 비슷하게. 한쪽이 비면 콜아웃·칩을 더하고, 넘치면 문장을 줄인다(카드 본문 2줄 이내).
5. **저장.** 정본은 `~/Desktop/cysjavis/<주제폴더>/<한글이름>_인포그래픽.html` (설교→`설교_성경`, 논문→`논문`, 강의→`강의_발표`). `<title>`은 2–4단어.
6. **내보내기.** `bash ~/.claude/skills/kbg-infographic/export.sh <정본.html>` → 같은 폴더에 PNG(2배)·PDF. 포스터가 2400px보다 길면 `KBG_H=높이`를 앞에 붙인다.
7. **확인.** PNG를 Read로 열어 겹침·줄바꿈 깨짐·빈 단을 본다. 고친 뒤 다시 내보낸다.
8. 사용자가 원하면 Artifact로 발행. 재발행은 반드시 기존 `url`을 넘긴다.

## 디자인 규칙

- 팔레트는 `:root` 토큰만 바꾼다. 기본: 잉크 #14161c, 다크 밴드 #141a2e, 강조 블루 #2f6bff, 핫 오렌지 #e8480c(나쁜 쪽/반전/경고에만).
- 숫자는 Space Grotesk, 코드·절 번호는 JetBrains Mono, 한글은 Pretendard. 한글 문장에 mono를 쓰지 않는다.
- 히어로의 큰 숫자는 단 하나. 오렌지는 화면에 3곳 이하.
- 섹션 제목 오른쪽 회색 태그라인은 "A ≠ B" 또는 짧은 구로 그 섹션의 주장을 요약한다.
- 성경 인용은 짧게(한 절 이내), 장절 표기.
