# Figma Deck — 흑백 + 컬러블록 발표자료 생성기

figma.com 마케팅 면의 디자인 시스템을 재현하는 스킬. 입력(원고·개요·자료)을 받아
**자체완결 HTML 슬라이드 덱 1개 파일**을 생성한다.

> 원본 스펙의 표현 그대로: **"깨끗한 책상 위에 놓인 포스트잇."**
> 프레임은 엄격한 흑백이고, 색은 섹션마다 딱 한 장씩 사건처럼 등장한다.
> 색을 늘리는 순간 포스트잇이 아니라 색종이 더미가 된다.

## 0. 시작 전 확인 (한 턴에 몰아서 질문)

1. **원고/자료** — 없으면 주제만 받아 개요부터 작성해 확인받는다
2. **챕터 수** — 챕터당 컬러블록 1색을 배정한다. 3~4챕터가 적정(색 7종이 있지만 다 쓰지 않는다)
3. **출력** — 화면 발표(기본) / PPTX 변환 / PDF 인쇄

## 1. 스타일 토큰 (절대 변경 금지)

```css
--ink:#000; --canvas:#fff;              /* 순흑·순백. 근사흑·오프화이트 아님 */
--hairline:#e6e6e6; --hairline-soft:#f1f1f1; --surface-soft:#f7f7f5;
/* 컬러블록 7종 — 섹션당 하나 */
--lime:#dceeb1; --lilac:#c5b0f4; --cream:#f4ecd6; --pink:#efd4d4;
--mint:#c8e6cd; --coral:#f3c9b6; --navy:#1f1d3d;
--magenta:#ff3d8b;   /* 프로모 CTA 전용 */
--success:#1ea64a;   /* 체크마크 원 */
```

**색 규칙 (위반 시 스타일 붕괴)**
- **한 화면에 컬러블록은 하나.** 두 블록이 한 뷰포트에 보이면 스펙 위반이다.
- **블록 두 개 사이에는 흰 캔버스가 반드시 돌아온다.** 색이 연속되면 사건이 배경이 된다.
- **중간 회색 텍스트를 쓰지 않는다.** 위계는 불투명도가 아니라 **웨이트**로 만든다.
  (이 규칙이 다른 화이트 계열 덱과 이 시스템을 가르는 지점이다.)
- 컬러블록에 그림자를 넣지 않는다.
- 문서화된 팔레트와 마젠타 밖의 악센트를 도입하지 않는다.

## 2. 타입 규칙 — 비표준 가변 웨이트

| 역할 | 크기(1920 스테이지) | 웨이트 | 자간 |
|---|---|---|---|
| 히어로 h1 | 172px | **340** | -3.44px |
| 섹션 오프너 h2 | 128px | **340** | -1.92px |
| 스토리 제목 h3 | 52px | **540** | -0.52px |
| 롱폼 인트로 | 52px | **340** | -0.52px |
| 카드 제목 | 48px | **700** | 0 |
| 리드 | 40px | **330** | -0.28px |
| 본문 | 36px | **320** | -0.52px |
| 보조 본문 | 32px | **330** | -0.28px |
| 링크·버튼 | 40px | **480** | -0.2px |
| eyebrow (mono) | 36px | 400 | +1.08px · 대문자 |
| 캡션 (mono) | 24px | 400 | +1.2px · 대문자 |

- 웨이트가 **320/330/340/480/540/700**이라는 점이 이 시스템의 특이점이다. 300·400·500으로
  반올림하지 않는다 — Inter 가변축이 이 값을 그대로 받는다.
- **카드 제목(700)이 유일한 굵은 자리**다. 다른 곳에 700을 쓰지 않는다.
- **mono는 eyebrow와 캡션에만**, 항상 대문자. 본문에 mono를 넣지 않는다.
- **폰트**: figmaSans는 사유 폰트다. 스펙이 지정한 오픈소스 대체가 **Inter(또는 Geist)**,
  mono는 **JetBrains Mono**다. 한글은 Pretendard가 받는다. `font-kerning:normal` 유지.

## 3. 슬라이드 아키타입 (8종 — 이 중에서만 조합)

| 코드 | 이름 | 배경 | 사용 시점 |
|---|---|---|---|
| F1 | 히어로 | 흰색 | 표지 (색을 넣지 않는다) |
| F2 | 컬러블록 | 파스텔 1색 | 챕터 선언 |
| F3 | 흰 캔버스 복귀 | 흰색 | **F2 다음에 필수** — 설명·타일 |
| F4 | 마퀴 + 카드 | 흰색 | 키워드 흘리기 + 기능 3-up |
| F5 | 두 번째 컬러블록 | 다른 파스텔 | 다음 챕터 |
| F6 | 비교 | 흰색 | 가격·포함 항목(초록 원 체크) |
| F7 | 네이비 블록 | `--navy` | 선언 (전체 1회) |
| F8 | 클로징 | 흰색 | 검정 pill + 흰 pill 짝 |

**리듬 규칙**
- **F2 → F3 → F5 → F3 …** 컬러블록과 흰 캔버스를 반드시 교차한다.
- 챕터당 색 하나를 배정하고 그 챕터 안에서는 색을 바꾸지 않는다.
- F7(네이비)은 전체 1회. 파스텔의 반전 짝이므로 무게가 있다.

## 4. 원고 → 슬라이드 분해 규칙

1. **컬러블록에는 선언만, 흰 캔버스에는 설명을.** 이 분업이 리듬의 핵심이다.
2. 컬러블록에 표·카드·목록을 넣지 않는다. 문장 하나와 부제 하나까지다.
3. 기능 나열은 카드 3-up(F4), 가격·포함 항목은 F6.
4. 키워드·고객사·태그는 마퀴 스트립으로 흘린다.
5. 마지막은 F8, **검정 pill + 흰 pill** 짝으로 닫는다.

## 5. 형태 규칙

- **모든 CTA는 pill, 모든 아이콘 버튼은 원.** CTA를 각지게 만들지 않는다.
- 보조 버튼의 여백은 **비대칭**(8px 18px 10px, 덱에서는 16/36/20)이다. 스펙 그대로 유지한다.
- 라운딩 사다리: 타일 `--r-md` → 카드·컬러블록 `--r-lg`(24px→48px) → 히어로 패널 `--r-xl`.
- 마젠타 pill은 **프로모 CTA 전용**이다. 일반 CTA에 쓰지 않는다.

## 6. 모션 규칙 (CSS만)

- 페이드 + 22px 상승, 0.6s, 간격 0.10s. 가볍고 명랑하게.
- 컬러블록이 슬라이드하거나 회전하지 않는다. 색은 등장하는 것이지 움직이는 것이 아니다.
- `@media print`: 애니메이션 해제, 슬라이드당 1페이지.

## 7. 빌드 절차

1. `template.html`을 골격으로 사용한다 — 토큰·8종 아키타입·마퀴·체크마크·발표자 노트 포함.
2. 원고를 4장 규칙으로 분해해 **슬라이드 시퀀스 표**(아키타입·블록 색·제목·본문)를 먼저 보여준다.
   **컬러블록이 연속되지 않는지, 챕터별 색이 고정됐는지 이 표에서 확인한다.**
3. `<section class="slide">` 단위로 생성. 블록 색은 `style="--blk:var(--lime)"`로 건다.
4. **발표자 노트**는 `data-note` 속성(HTML 태그 가능, `"` 금지). `S` 토글, 기본 숨김.
5. `{주제}-deck.html`로 저장. **PPTX 변환**은 `../monoline-deck/deck2pptx.py` 공유.
6. **검증**: 첫·중간·마지막 장을 캡처해 점검한다 —
   ① 컬러블록이 두 장 연속인가 ② 중간 회색 글자가 생겼는가
   ③ CTA가 각져졌는가 ④ mono가 본문에 들어갔는가
   ⑤ 웨이트를 300·400·500으로 반올림했는가 ⑥ 컬러블록에 그림자가 붙었는가.

**함정**
- 한글 파일명은 Edge 헤드리스 캡처가 안 된다. 스크래치패드에 ASCII 이름으로 복사해 찍는다.
  `--user-data-dir`을 새로 주면 Edge 새 탭이 찍히므로 쓰지 않는다.
- **Pretendard는 가변 폰트지만 320/330/340의 차이가 한글에서 거의 보이지 않는다.** 한글 위계는
  웨이트 대신 **크기와 여백**으로 보강한다. 라틴은 스펙값을 그대로 쓴다.
- `.block.full`은 음수 마진으로 슬라이드 여백을 상쇄해 전면 색면을 만든다. `--pad`를 바꾸면
  이 값도 같이 바꿔야 한다.

## 8. 조작법 (생성물 안내에 포함할 것)

- `→` / `Space` 다음, `←` 이전, `Home`/`End` 처음·끝, 화면 좌우 클릭·스와이프
- **`S` 발표자 노트 토글** (기본 숨김)
- `#3` 해시로 특정 장 직행, `?shot#3`은 캡처 모드
- 브라우저 인쇄(Ctrl+P, 가로)로 PDF 출력
