# Dell96 Deck — 1996 카탈로그 웹 발표자료 생성기

1996년 12월 Dell.com 홈페이지의 디자인 시스템을 재현하는 스킬. 입력(원고·개요·자료)을 받아
**자체완결 HTML 슬라이드 덱 1개 파일**을 생성한다.

> 이 스타일은 CSS가 보급되기 2년 전, "디자인 시스템"이라는 말이 생기기 3년 전의 화면이다.
> 레이아웃은 `<table>`, 폰트는 OS 기본 3종, 색은 8비트 세이프 플랫 채움, 장식은 손으로 자른 GIF 스티커.
> **부드럽게 만드는 모든 시도(라운딩·그라디언트·소프트 섀도·이징)가 시대를 깬다.**

## 0. 시작 전 확인 (한 턴에 몰아서 질문)

사용자가 이미 밝힌 항목은 건너뛴다:
1. **원고/자료** — 없으면 주제만 받아 개요부터 작성해 확인받는다
2. **챕터 수** — 챕터마다 tint 1색을 배정하므로 3~5개가 적정. 8색을 다 쓰면 색견본이 된다
3. **사진** — 리본카드 우측 노치에 들어갈 이미지. 없으면 흰 박스 + 캡션(`data-cap`)만으로도 성립한다
   (1996 GIF는 80~120px 저해상도였으므로 **사진 없는 편이 오히려 시대에 맞다**)
4. **출력** — 화면 발표(기본) / PPTX 변환 / PDF 인쇄
5. **레트로 강도** — 진지한 업무 발표인가(스티커·전화번호 최소), 시대 재현이 목적인가(스티커 적극)

## 1. 스타일 토큰 (절대 변경 금지 — 팔레트는 닫혀 있다)

```css
--red:#e91d2a;     /* CTA 패널 + 전화번호 전용. 카드 채움 금지 */
--yellow:#fcc20f;  /* 스티커 */
--purple:#6a26a4;  /* "BUY a DELL"의 a 스트라이프에만 */
--link:#0000ee;    /* 넷스케이프 3.x 링크 블루. 밑줄 필수 */
--ink:#000; --paper:#fff;   /* 순검정·순백. 근사흑·오프화이트 금지 */
/* 리본카드 여덟 색 — 챕터/항목군당 하나 */
--olive:#8e8a25; --sage:#b3bd95; --salmon:#d77a7a; --peach:#e6915d;
--lime:#c0d4a7;  --sky:#9ab6c8;  --steel:#a5b8c0;  --periwinkle:#8c9ae0;
```

**색 규칙 (위반 시 스타일 붕괴)**
- **빨강은 페이지당 한 번.** CTA 패널(`.cta`) 또는 전화번호(`.phone`). 두 개 놓으면 주의의 극점이 사라진다.
- 여덟 tint는 **계열로 쓴다** — 챕터당 1색을 정하고 그 챕터 안에서는 바꾸지 않는다.
- 이 목록 밖의 색을 추가하지 않는다. 톤을 밝히거나 채도를 올리는 것도 추가에 해당한다.
  tint는 채도가 있으나 선명하지 않다 — GIF 시대 웹세이프 양자화의 흔적이 그 특징이다.
- 초록은 푸터 아이콘을 잇는 괘선(#2f8b2f) 하나뿐이다. 다른 곳에 쓰지 않는다.

## 2. 타입 규칙 (UI는 산세리프, 본문은 세리프 — 현대의 반대)

| 역할 | 폰트 | 크기(1920 스테이지) | 웨이트 |
|---|---|---|---|
| 아이브로 제목 | **Arial Black** | 72px | 900 · 대문자 |
| 서브 헤드라인 | Arial Black | 48px | 900 |
| 배너·제품 타이틀 | **Helvetica** | 32px | 700 · 대문자 |
| 리본 제목바 | Helvetica | 28px | 700 · 대문자 |
| 본문·카드 내용 | **Times New Roman** | 28px | 400 |
| 각주·작은 본문 | Times | 24px | 400 |
| 저작권 | Times | 22px | 400 |
| 버튼·스티커·라벨 | Helvetica | 24px | 700 · 대문자 |

- 표기 크기는 모두 **원본 웹 토큰 × 2** (Arial Black 36 → 72px). 원본은 760px 고정폭 페이지였다.
- **본문을 산세리프로 바꾸면 이 스타일이 아니다.** Times Roman 세리프가 카탈로그 감각의 핵심이다.
- 디스플레이는 항상 가장 무거운 웨이트(900). 중간 웨이트는 이 시대에 존재하지 않았다.
- **자간 조정 0.** 1996 픽셀 폰트는 트래킹을 보상하지 않았다. 브라우저 기본 커닝 그대로 둔다.
- **한글 폴백**: Arial Black·Times에는 한글이 없다. 템플릿이 헤드라인용 Pretendard(900),
  본문용 Noto Serif KR(400)을 싣는다. 라틴 스택은 절대 웹폰트로 교체하지 않는다 —
  영문 대문자가 Arial Black/Helvetica로 나오는 것이 시대 표식이다.

## 3. 화면 구조 (16:9 / 1920×1080 고정)

```
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓ ← 검정 액자 16px (원본 8px × 2)
┃ ████ 배너: 대문자 태그라인   [스티커] 1-800… ┃ ← 검정 띠 + 빨간 전화번호
┃ ▓▓▓▓ 아이브로 색블록: 제목 900 대문자 ▓▓▓▓  ┃ ← 챕터 색
┃ ┌─────────────────────────┐ ┌───┐        ┃
┃ │ 흰 제목바 (Helvetica Bold)│ │사진│        ┃ ← 리본카드: 제목바 + tint 본문
┃ │ tint 본문 (Times Roman)  │ └───┘        ┃    + 우측 노치(위아래로 삐져나옴)
┃ └─────────────────────────┘              ┃
┃ ─────── 푸터: 아이콘 4개 + 파란 Copyright ── ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

- 액자는 **협상 대상이 아니다.** 이 검정 테두리가 브랜드의 최대 식별자다.
- 2단 구조는 좌측 레일 27% / 우측 본문 73% (원본 홈페이지 비율).
- **밀도가 미덕이다.** 액자 안에 빈 흰 바닥을 남기지 않는다 — 템플릿의 flex가 리본·표를
  남은 높이에 균등 분배한다. 여백을 남기려면 `.stack.top`으로 명시한다.

## 4. 슬라이드 아키타입 (8종 — 이 중에서만 조합)

| 코드 | 이름 | 구성 | 사용 시점 |
|---|---|---|---|
| D1 | 표지 | 배너 + 아이브로 제목 + 빨간 CTA + 차례 표 | 첫 장 |
| D2 | 챕터 표지 | tint 색블록 전면 + Arial Black 제목 | 챕터 전환 |
| D3 | 리본 스택 | 리본카드 3~4개 (제목바 + tint 본문 + 사진 노치) | **주력** — 항목·사례 나열 |
| D4 | 2단 구조 | 좌측 링크 그리드 + 빨간 CTA / 우측 리본 스택 | 개요·한눈에 보기 |
| D5 | 수치 블록 | tint 색블록 3~4개에 Arial Black 숫자 + 해석 리본 | 지표·통계 |
| D6 | 표 | HTML 3.2 테이블 (2px 검정 괘선) | 비교·명세 |
| D7 | 선언 | 중앙 진술 + NEW! 버스트 + 원형 인증씰 | 전환·못 박기 |
| D8 | 클로징 | 실행 표 + 푸터 아이콘 내비 + 파란 Copyright | 마지막 장 |

**리듬 규칙**
- D3(리본 스택)이 전체의 40~50%다. 이 스타일은 리본카드로 말한다.
- **D7(선언)은 전체 2~3회.** 스티커가 흔해지면 "핀으로 꽂은" 느낌이 사라진다.
  선언 장을 색블록 전면으로 하려면 `.paper.tint`를 쓴다.
- D2 챕터 표지 → D3 리본 → D5/D6 수치·표 → D3 리본 → D7 선언 순으로 챕터를 닫는다.
- 리본카드는 한 장에 **3~4개가 한계**. 5개부터는 슬라이드를 쪼갠다.

## 5. 원고 → 슬라이드 분해 규칙

1. **한 항목 = 한 리본카드.** 제목바에 대문자 명사구(Helvetica Bold), 본문에 Times 두 줄.
   - 원고: "게네테토는 명령형 수동태로, 체념이 아니라 요청이다"
     → 제목바 `명령형 수동태` · 본문 `게네테토는 신적 수동태다. 행위자는 하나님이며, 체념이 아니라 요청이다.`
2. 원고를 **3~5개 챕터**로 묶고 챕터마다 tint 1색 배정. 챕터 첫 장은 D2.
3. 숫자는 리본 본문에 넣지 말고 **D5 수치 블록**으로 뺀다. Arial Black 숫자가 이 시대의 차트다.
4. 비교·명세는 **D6 표**로. 1996 레이아웃은 전부 테이블이었으므로 표가 가장 시대에 맞다.
5. 챕터 끝 = D7 선언 1장.
6. 새로 추가된 항목·최신 정보에는 **NEW! 버스트**를 붙인다 — 이 스티커가 원래 그 용도였다.

## 6. 스티커·베벨 규칙

- 스티커는 **하드 베벨**로 뜬다: `filter:drop-shadow(3px 3px 0 #000)`. 블러가 있는 섀도는 금지.
- `.sticker.burst`는 -15° 회전. 테이프로 붙인 느낌이 이 회전에서 나온다.
- 사진 노치(`.shot`)는 리본 우측에서 **위아래로 삐져나온다**. 라운딩·클립패스로 다듬지 않는다.
  사진이 없으면 흰 박스 + `data-cap="FIG. 1"` 캡션으로 두거나 `.fill.wide`로 자리를 회수한다.
- 원형은 인증씰(`.seal`)뿐이다. 다른 요소에 `border-radius`를 주지 않는다.

## 7. 모션 규칙 (CSS만)

- **1996엔 트랜지션이 없었다.** 요소는 페이드하지 않고 `steps(1)`로 **딱 켜진다**.
  등장 순서만 유지(d1~d6, 간격 0.14s). 부드러운 이징을 넣는 순간 현대 덱이 된다.
- 배경 줌·패럴랙스·호버 애니메이션 없음.
- `@media print`: 애니메이션 해제, 슬라이드당 1페이지.

## 8. 빌드 절차

1. `template.html`(이 스킬 폴더)을 골격으로 사용한다 — 토큰·8종 아키타입·스티커·발표자 노트·내비가
   다 들어 있다. 예시 슬라이드 8장은 교체용 참조다.
2. 원고를 5장 규칙으로 분해해 **슬라이드 시퀀스 표**(아키타입·챕터 tint·제목바·본문·수치·스티커)를
   먼저 만들어 사용자에게 보여준다.
3. `<section class="slide">` 단위로 생성. 챕터 색은 요소에 `style="--tint:var(--sage)"`로 건다.
4. **발표자 노트**는 각 `<section>`의 `data-note` 속성에 넣는다(HTML 태그 사용 가능, `"` 금지).
   `S`로 토글되며 기본 숨김이다. 슬라이드에 못 담은 출처·수치·배치 주의를 여기 남긴다.
5. `{주제}-deck.html`로 저장.
6. **PPTX 변환**은 `../monoline-deck/deck2pptx.py`를 공유한다(`class="slide"` + `?shot#N` 규약 동일).
7. **검증**: 첫·중간·마지막 장을 캡처해 점검한다 —
   ① 라운딩이 생긴 요소가 있는가(인증씰 외 전부 0px)
   ② 본문이 산세리프로 바뀌었는가 ③ 빨강이 한 장에 두 번 나왔는가
   ④ 액자 안에 빈 흰 바닥이 남았는가 ⑤ 소프트 섀도·그라디언트가 섞였는가.

**함정**
- **`.paper`는 세로 flex다.** 새 블록을 추가할 때 `flex:1`을 줘야 페이지를 채우고, `flex:0 0 auto`면
  자기 높이만 차지한다. 빈 흰 바닥이 남는 건 대개 이걸 안 준 경우다.
- `.foot`은 `margin-top:auto`로 바닥에 붙는다(absolute 아님). absolute로 바꾸면 본문과 겹친다.
- **한글 파일명으로 저장하면 Edge 헤드리스 캡처가 안 된다.** 검증할 땐 스크래치패드에 ASCII 이름으로
  복사해 찍는다. `--user-data-dir`을 새로 주면 Edge 새 탭 화면이 찍히므로 쓰지 않는다.
- Arial Black은 Windows/macOS 기본 폰트지만 리눅스에는 없다. 폴백이 Pretendard 900으로 떨어지면
  영문 대문자의 스텐실 느낌이 약해진다 — 발표 PC가 리눅스면 사용자에게 알린다.

## 9. 조작법 (생성물 안내에 포함할 것)

- `→` / `Space` 다음, `←` 이전, `Home`/`End` 처음·끝, 화면 좌우 클릭·스와이프도 동작
- **`S` 발표자 노트 토글** (기본 숨김 · 켜면 슬라이드가 위로 붙으며 축소됨)
- `#3` 해시로 특정 장 직행, `?shot#3`은 페이지 표시를 숨긴 캡처 모드
- 브라우저 인쇄(Ctrl+P, 가로)로 PDF 출력
