# Boneun Deck — "읽지 않고 보는 PPT" 원칙 엔진

LG전자 디자이너 윤춘근의 직장인 PPT 디자인 강의(오빠두엑셀)에서 추출한 **제작 원칙 전체**를
자동 적용하는 스킬. 입력(원고·자료)을 받아 자체완결 HTML 덱을 만들고 PPTX로 변환한다.

> 대전제: **청중은 절대 읽지 않는다.** 보고서는 1:1로 읽히지만 프레젠테이션은 1:다수가
> 제한된 시간에 화면으로 "본다". 그러므로 읽는 디자인이 아니라 보는 디자인을 한다.
> 디자인의 본질은 꾸미기가 아니라 **정리** — 더하지 않고 **뺀다**.

## 0. 시작 전 확인 (한 턴에 몰아서 질문)

1. **원고/자료** — 없으면 주제만 받아 개요부터
2. **주제의 맥락색** — 브랜드·로고·주제 연상색이 있는가? (코카콜라=빨강, 스타벅스=초록)
   있으면 그 색이 포인트 컬러, 없으면 **무채색으로 간다** (무채색만으로 충분히 성공적이다)
3. **히어로 이미지** — (a) 사용자 제공 (b) Unsplash/Pexels 검색어를 제안해 받아오기 (c) 이미지 없이 텍스트 슬라이드만
4. **출력** — 화면 발표 / PPTX / PDF

## 1. 4대 철칙 (강의의 뼈대 — 모든 결정의 기준)

1. **빼기가 디자인이다.** 내용·컬러·폰트 종류·이미지 개수·애니메이션 전부 최소로.
   내용이 많으면 한 장에 채우지 말고 **장수를 늘린다. 한 슬라이드 = 한 주제.**
2. **압축 파이프라인: 문단 → 문장 → 키워드.** 원고의 문단을 문장으로, 문장을 단어로 줄인다.
   슬라이드에는 키워드만 남기고 나머지는 발표자가 말로 한다.
3. **우선순위: 글꼴 > 컬러 > 이미지.** 이 셋만 잡아도 인상이 달라진다.
4. **기성 템플릿 금지.** 주제와 무관한 장식은 소음이다. 여백은 눈이 숨 쉬는 공간이다.

## 2. 글꼴 규칙

**3그룹 용법**
| 그룹 | 성격 | 쓰는 곳 | 대표 (모두 무료) |
|---|---|---|---|
| 고딕(San Serif) | 모던·도시적, 디지털 가독성 | **기본. 키워드 전달의 표준** | Pretendard(기본), 본고딕, 나눔스퀘어, G마켓 산스(헤드라인용) |
| 명조(Serif) | 섬세·유연·품격, 인쇄 가독성 | 웰빙·품격·감성 주제, 고딕과의 대비 연출 | 본명조(=Noto Serif KR), 마루 부리 |
| 캘리 | 손글씨 감성, 가독성 낮음 | **따옴표 안 인용·브레인스토밍 연출만.** 본문 절대 금지 | 나눔손글씨 |

- **덱 전체에 폰트는 한 가족만.** 강약은 폰트를 바꾸는 게 아니라 **같은 가족의 굵기**로 만든다:
  Light(300) 바탕 + 강조 키워드만 ExtraBold(800). 이 굵기 대비가 이 스킬 타이포의 전부다.
- 기본 폰트는 **Pretendard** — 본고딕을 한글에 맞게 튜닝, 한/영 커버, 완전 무료, 자간 최적화.
- **자간은 살짝 좁힌다** (템플릿에 `letter-spacing:-.012em`, 제목 `-.03em` 반영 완료).
  PowerPoint로 직접 만들 땐: 글꼴 옵션 → 기타 간격 → **좁게 0.5~2pt**. '빽빽하게' 프리셋은 영문 기준이라 한글에 과하다.
- **금지**: 굴림체, 여러 폰트 남발, 화려한 장식 폰트, (가능하면) 맑은 고딕. 아리따 부리는 상업적 사용 주의.

## 3. 컬러 규칙 — 6:3:1

- **총 3색을 넘기지 않는다**: 배경 6 : 본문·보조 3 : 포인트 1.
- 포인트 컬러는 **주제의 맥락에서만** 나온다. 로고·대표 이미지에서 스포이드(추출)한 색.
  맥락색이 없으면 **포인트 없이 무채색**(흰·회·검)으로 — 그게 정답이고 고급스럽다.
- 포인트를 정했으면 **처음부터 끝까지 그 한 색**만. 중간에 다른 색이 나오면 통일성 파괴.
- 어두운 배경 위 텍스트는 **명도 대비**부터 확인 — 안 읽히면 배경 명도를 낮춰서 가독성 확보.
- 배색이 막히면: [Color Hunt](https://colorhunt.co)에서 팔레트, [Adobe Color](https://color.adobe.com)의
  '테마 추출'에 대표 이미지를 올리면 5색을 뽑아준다 → 그중 6/3/1을 배정.
- 템플릿에선 `--c6`(배경) `--c3`(잉크) `--c1`(포인트) 변수 3개가 전부다. 맥락색이 있으면 `--c1`만 교체.

## 4. 이미지 규칙 — 히어로 이미지 5조건

이미지 하나에 텍스트 한 줄 얹으면 완성되는 감성 이미지(넷플릭스·애플식)를 "히어로 이미지"라 한다.

1. **주제 연관성** — 예뻐도 주제와 무관하면 탈락. 키워드와 배경이 매칭돼야 공감이 생긴다
2. **자연스러움** — '하나 둘 셋 찰칵' 연출 스톡사진(게티 스타일) 금지. 스냅 느낌
3. **고해상도** — 최소 1920×1080. 로고는 특히 (공식 규정 이미지 사용)
4. **비비드 금지** — 채도 낮은, 필터 먹인 듯 톤 다운된 이미지
5. **여백** — 텍스트 앉힐 자리가 있는 이미지. 정보량 많은 복잡한 사진 탈락

- 여백이 없으면 템플릿의 두 장치를 쓴다: `.mat`(매트한 반투명 도형) 또는 `.grad`(그라디언트).
- 수급처: **Unsplash**(완전 무료), **Pexels**(영상도 무료), **Artvee**(고전 회화 고해상도).
  사용자에게 검색 키워드(영문)를 제안하고 파일을 받거나, 직접 수급 가능하면 받아온다.

## 5. 슬라이드 아키타입 (8종 — template.html의 P1~P8)

| 코드 | 이름 | 구성 | 사용 시점 |
|---|---|---|---|
| P1 | 히어로 표지 | 풀블리드 이미지 + 하단 그라디언트 + 제목 한 줄 | 첫 장 |
| P2 | 키워드 | 무채색 배경 + Light/ExtraBold 큰 문장 | 핵심 주장·전환 |
| P3 | 본문 리스트 | 압축된 문장 3~4줄, 키워드만 굵게 | 근거·세부 |
| P4 | 히어로+키워드 | 이미지 + 좌측 그라디언트 + 키워드 | 개념에 감성 입히기 |
| P5 | 명조 콘셉트 | serif-mode, 품격·감성 주제 | 톤 전환 |
| P6 | 인용 | 캘리 따옴표 + 고딕 출처 | 인용·한마디 |
| P7 | 명조 vs 고딕 | 화면 반분, 대비 연출 | 대조 개념 |
| P8 | 챕터 | 포인트 컬러 전면 + 챕터명 | 섹션 구분 |

**리듬**: P2·P3(텍스트)가 기본 흐름, 챕터마다 P8로 끊고, 감성이 필요한 곳에만 P1/P4.
P5·P6·P7은 덱 전체에서 각 1~2회. 같은 아키타입 3연속 금지.

## 6. 원고 → 슬라이드 분해 규칙

1. 원고를 **챕터 2~4개**로 묶는다 (챕터당 P8 한 장).
2. 각 문단에서 **한 문장**을 뽑고, 그 문장에서 **키워드 1~3개**를 뽑는다.
   - 키워드가 주장이면 → P2 (키워드만 크게, 굵기로 강조)
   - 근거·나열이면 → P3 (줄당 볼드 1구, 3~4줄 한계)
   - 감성·장면이면 → P1/P4 (이미지 + 한 줄)
3. 슬라이드의 텍스트가 **3줄을 넘으면 두 장으로 쪼갠다.** 채우지 말고 늘린다.
4. 밑줄·기울임·그림자·워드아트 금지. 강조 수단은 **굵기와 포인트 컬러(.pt) 둘뿐**이다.
5. 애니메이션은 페이드뿐. 그마저도 줄일수록 좋다.

## 7. 빌드 절차

1. `template.html`을 골격으로 사용 (토큰·8종 아키타입·모션·내비 완비).
2. 원고를 6단계로 분해해 **슬라이드 시퀀스 표**(아키타입·키워드·굵게 할 구·이미지 검색어·컬러)를 먼저 보여준다.
3. 맥락색 결정(§0-2) → `--c1` 교체 여부. 이미지 수급(§4) → `img/` 폴더에 저장, 상대경로 참조.
4. `{주제}-deck.html`로 저장.
5. **검증 체크리스트** (헤드리스 캡처로 확인):
   ① 폰트가 Pretendard 한 가족인가(명조·캘리는 규정 위치에만) ② 컬러가 3색 이내이고 포인트가 일관된가
   ③ 슬라이드당 주제 하나·텍스트 3줄 이내인가 ④ 이미지가 5조건을 지키는가(저해상도·비비드·연출 스톡 탈락)
   ⑤ 어두운 이미지 위 텍스트의 명도 대비가 충분한가

## 8. 조작법 + PPTX 변환

- `→`/`Space` 다음, `←` 이전, `Home`/`End`, 좌/우 클릭. `#N` 바로가기, `?shot` 캡처 모드. Ctrl+P → PDF.

## 9. 부록 — PowerPoint에서 직접 작업하는 사용자를 위한 강의 팁

- **자간**: 홈 → 글꼴 → 문자 간격(가나) → 기타 간격 → 좁게 0.5~2pt
- **스포이드**: 도형 채우기 → 다른 채우기 색 → 스포이드로 이미지·로고에서 색 추출 → 필요시 명도 조정
- **글꼴 포함 저장**: 파일 → 옵션 → 저장 → "파일의 글꼴 포함" (공유 시 폰트 깨짐 방지, 용량은 커짐)
- 배색 참고: Color Hunt 팔레트를 캡처해 붙여넣고 스포이드로 찍으면 헥사값 입력 없이 적용된다
