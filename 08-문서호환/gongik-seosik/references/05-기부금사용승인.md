# 기본재산 편입예외 기부금사용 승인 서식 패키지

> 출처: 서울특별시교육청 「2026 공익법인 실무지침서」 Ⅲ. 법인의 관리·운영 — 1. 재산관리 5) 기본재산편입예외 기부금 사용 승인 (책 102~110쪽)

## 1. 절차 개요

- **근거**: 공익법인의 설립·운영에 관한 법률 시행령(공익령) 제16조 제1항 제2호, 기부금품법 시행령 제1조의3 등
- **처리과정**: 승인신청 → 승인 → 집행(이행) → 결과보고
- **원칙과 예외**: 기부에 의하거나 기타 무상으로 취득한 재산은 **기본재산에 편입하는 것이 원칙**이나, 기부목적에 비추어 기본재산에 편입하기 곤란한 **"합리성·타당성·객관성을 띤 사유"**가 존재할 경우 주무관청의 **사전 승인**을 얻어 기본재산에 편입하지 않고 목적사업에 직접 사용 가능
  - ☞ 수혜자 한정 기부 시 법인 정관상 수혜자 한정 내용과 일치하는지 판단하여야 함
- **승인 대상 재산의 제한**: 목적사업에 직접 사용 가능한 **현금, 물품 및 전자화폐·선불전자지급수단·선불카드 등 금전적 가치를 갖는 물건** 등만 가능. **주식·부동산·채권 등은 직접 목적사업 사용이 불가능하므로 승인 대상이 아님**
  - ☞ 주식·부동산·채권 등의 기부금품은 정관상 기본재산 증자 대상이 원칙임 (단, 무수익 재산인 경우 매도 처분 후 예금 증자 대상)
- **운영비·인건비 사용 한도**: 기부금의 최대 15% 이내에서 직접 목적사업수행에 필요한 운영비, 인건비 사용 등을 승인할 수 있음

  ＊기부금 중 운영비 등 사용 비율 기준표

  | 모집 금액 | 적용 비율 |
  |---|---|
  | 10억원 이하 | 15% 이하 |
  | 10억원 초과 100억원 이하 | 13% 이하 |
  | 100억원 초과 200억원 이하 | 12% 이하 |
  | 200억원 초과 | 10% 이하 |

- **사용 제한**: 사용 승인된 기부금은 승인된 해당 목적사업 등 외에는 사용이 불가능함
- **회비와의 구분**: 강제성과 반대급부성이 없이 무상 취득하는 "기부금"과 회원에 대한 강제성과 반대급부성이 있는 사단법인의 "회비"는 성격이 다르므로, 사단법인 회비는 기부금 사용 승인 대상이 아님
  - ☞ 단, 명목상 "회비"이나 납부의 강제성과 반대급부가 없어 성격상 "기부금"에 해당할 경우 기부금 사용 승인 대상으로 볼 수도 있으므로 사단법인 자체 판단 필요
  - 참고 심판례: "특별회비"의 성격(조세심판원 2023. 8. 22. 조심 2022서6716) — 청구법인이 지정기부금인 특별회비로 쟁점회비를 납부한 사실 및 기부목적 등이 확인되고, 이후 쟁점법인으로부터 쟁점회비 납부에 대한 기부금 영수증을 발급받아 제출한 점 등에 비추어 쟁점회비를 지정기부금으로 볼 수 있음
- **실태조사 지적사례**
  - 기부금 사용승인을 받지 않고 임의 사용: (주)○○○으로부터 기부받은 금○○원을 기본재산으로 편입하거나 기본재산편입예외 기부금사용승인을 받지 않고 장학금을 지급하였음
    - ☞ 기부금을 받았을 경우에는 기본재산에 편입이 원칙이나 기부목적 상 기본재산에 편입하기 곤란한 사유가 있는 경우에는 기본재산편입예외 기부금사용 사전 승인을 받아야 함
  - 기부금 사용승인 내역과 다르게 임의 사용: 장학사업 용도로 목적을 지정하여 기부 및 사용 승인을 받은 금○○원을 학술지원금 지급 목적으로 사용하였음
    - ☞ 기부금은 승인된 해당 목적사업 외에는 사용이 불가능함

## 3. 서식별 템플릿과 작성방법

### 서식 ① — 기본재산 편입예외 기부금사용승인 신청 공문

**용도**: 서울특별시교육감(평생교육과장) 앞으로 승인을 신청하는 대외 발송 공문.

**템플릿**:

```
                    재단법인 {법인명}

수신자   서울특별시교육감(평생교육과장)
(경유)
제목   기본재산편입예외 기부금사용승인 신청공문

「공익법인의 설립·운영에 관한 법률 시행령」 제16조 제1항 2호의 규정에 의하여
붙임과 같이 기본재산편입예외 기부금사용 승인을 신청하오니 승인하여 주시기
바랍니다.

붙임  1. 사유서 1부.
      2. (지정기부금의 경우)기부증서 사본 1부.
      3. 기부금 사용계획서 1부.
      4. 기부자별 기부금액 목록 1부.
      5. 재산 보유증명서(통장사본 또는 거래내역서) 1부.
      6. 이사회(총회) 회의록 1부.  끝.
      ※ 사단: 총회회의록, 재적회원명부, 참석자 서명부(위임 시, 위임장 첨부) 추가 제출

                재단법인 {법인명} (법인인감)

기안자          사무국장               이사장

시행  {법인명}-{문서번호}    ( {연월일} )  접수  (          )
우 {우편번호}  {법인 소재지 주소}          홈페이지 주소 {홈페이지 주소}
전화 {전화번호}  전송 {팩스번호}  담당자 전자우편  {담당자 이메일} /
```

**작성방법·주의사항**:
- ※ 법인주소, 전화번호, 팩스번호, 담당자 전자우편을 기재하여 주시기 바랍니다. (원문 주기)
- 근거 법령: 공익법인의 설립·운영에 관한 법률 시행령 제16조 제1항 제2호
- 결재선(기안자–사무국장–이사장)을 갖추고 법인인감을 날인한다.

### 서식 ② — 사유서

**용도**: 기부금을 기본재산에 편입하지 않고 목적사업에 직접 사용하려는 사유를 소명하는 문서.

**템플릿**:

```
             기본재산 편입예외 기부금 사용 사유서

  {기부자 성명} 외 {인원}명이 {기부목적(예: 장학사업 및 학술연구 지원)}을
  목적으로 현금 {현금 기부액}과 {현물 평가액} 상당의 현물을 기부한 바,
  현금 {현금 기부액} 중 기본재산으로 {기본재산 편입액}을 편입하고 나머지
  {잔여 현금액}과 {현물 평가액}의 현물 기부금품은 {편입 곤란 사유(예: 법인
  운용소득이 줄어 목적사업의 수행에 어려움이 있기에)} 기본재산에 편입하지
  않고 기부 의도와 같이 {사용 시기·용도(예: 2026년도 상반기 장학사업 및
  학술연구 지원)}에 사용하고자 합니다.

                                        {연} 년  {월} 월  {일} 일

                              재단법인 {법인명} 이사장 {이사장 성명} (인)

  서울특별시교육감 귀하
```

**작성방법·주의사항**:
- 기본재산에 편입하기 곤란한 "합리성·타당성·객관성을 띤 사유"가 드러나도록 기부 경위, 편입/미편입 금액의 구분, 사용 용도·시기를 구체적으로 기재한다.
- 지침서 예시문: "◌◌◌ 이사장 외 39명이 장학사업 및 학술연구 지원을 목적으로 현금 6억원과 4,500,000원 상당의 현물을 기부한 바, 현금 6억원 중 기본재산으로 5억원을 편입하고 나머지 1억원과 4,500,000원의 현물 기부금품은 법인 운용소득이 줄어 목적사업의 수행에 어려움이 있기에 기본재산에 편입하지 않고 기부 의도와 같이 2026년도 상반기 장학사업 및 학술연구 지원에 사용하고자 합니다."

### 서식 ③ — 기부증서(지정기부금의 경우)

**용도**: 지정기부금의 기부 목적·재산 내역을 기부자가 증명하는 문서. 기부영수증으로 대체 불가.

**템플릿**:

```
                  기부증서(지정기부금)

본인 소유 다음의 재산을 재단법인 {법인명}에 무상 기부합니다.

  【기부목적】
  - 예) 당 기부금은 법인 기본재산에 편입하지 않고 정관상 목적사업인
        "{목적사업 1}" 및 "{목적사업 2}" 용도로만 사용하기를 희망함
  - 예) 당 기부금은 법인 기본재산에 편입하여 해당 운용소득으로 목적사업을
        수행하기를 희망함
  ☞ 지정기부금의 경우 기부 목적에 따라 금액·용도 등을 분명히 기록함

                                        {연} 년  {월} 월  {일} 일

                                     위 기부자  {기부자 성명} (인)

재단법인 {법인명} 이사장 {이사장 성명} 귀하
```

**기부재산의 표시** (표):

| 재산명 | 종별 | 수량 | 금액 | 비고 |
|---|---|---|---|---|
| 예금 (법인 계좌번호 기재) | 현금 | {계좌 수}계좌 | {금액} | 기본재산 편입희망 |
| 예금 (법인 계좌번호 기재) | 현금 | {계좌 수}계좌 | {금액} | 보통재산 |
| {현물명} ({단가}원/{단위}) | 현물 | {수량} | {금액} | 보통재산 |
| {현물명} ({단가}원/{단위}) | 현물 | {수량} | {금액} | 보통재산 |
| 계 | | | {합계액} | |

(지침서 예시: 예금 1계좌 500,000,000원 기본재산 편입희망 / 예금 1계좌 100,000,000원 보통재산 / △△△ 방한 패딩점퍼(200,000원/벌) 현물 20벌 4,000,000원 보통재산 / □□□ 기프트카드(50,000원/장) 현물 10장 500,000원 보통재산 / 계 604,500,000원)

**작성방법·주의사항**:
- ☞ 현금: 법인 명의 통장사본 등 금융기관 예치 입증 서류 첨부
- ☞ 현물: ① 기부자 = 생산자: 원가명세서, 장부가액 확인서 등 제조원가 입증 서류 첨부 / ② 기부자 ≠ 생산자: 신용카드 매입 전표 등 시가 입증 서류 첨부
- 기부증서·기부금 사용계획서·기부자 명단·재산 보유증명서 상의 금액이 모두 일치해야 함

### 서식 ④ — 기부금 사용계획서

**용도**: 승인 대상 기부금의 사용내역·지급시기·지급액·세부내역을 명시하는 계획서.

**템플릿**:

```
                     기부금 사용계획서

                          법인명: 재단법인 {법인명}
```
