# 예산·결산 연례보고 서식 패키지

> 출처: 서울특별시교육청 「2026 공익법인 실무지침서」 pp.245~273 (Ⅲ. 법인의 관리·운영 5. 회계관리)
> 근거: 「공익법인의 설립·운영에 관한 법률」 제12조, 같은 법 시행령 제19조, 공익법인회계기준, 공익법인회계기준 실무지침서(기획재정부, 2018)

## 1. 절차 개요

공익법인은 주무관청(서울특별시교육감·평생교육과)에 매년 두 가지 보고 의무를 이행한다.

| 구분 | 기한 | 근거 |
|---|---|---|
| ① 사업계획 및 예산서 제출 | **회계연도 개시 1개월 전까지** | 공익법 제12조②, 공익령 제19조 |
| ② 사업실적 및 결산서 제출 | 회계연도 종료 후 제출 (지침서 본문 표기 "종료 후 3개월 이내", 벌칙 조항 인용부 표기 "종료 후 2개월 이내" — 실제 공문 시행 예시는 3월 초) | 공익법 제12조②, 공익령 제19조 |

**미제출 시 제재** (공익법 제19조②·③):
- 기한 내 사업계획·예산 또는 사업실적·결산을 첨부서류와 함께 제출·보고하지 아니하거나 거짓으로 제출·보고한 경우 → **1년 이하의 징역 또는 1,000만원 이하의 벌금**
- 이사나 감사가 위 죄를 범한 때에는 행위자뿐 아니라 **그 공익법인에도 벌금형 부과**(양벌). 다만 법인이 위반행위 방지를 위해 상당한 주의·감독을 게을리하지 아니한 때와 주무관청이 추천한 감사의 행위는 제외.
- 국세청 결산공시 후 수정 사항이 발생하여 재공시한 경우 즉시 주무관청에 재공시 결산자료를 추가 제출하여야 함.
- 결산 자체 체크리스트에서 미비 사항 발견 시 즉시 보완·시정조치.

- 총괄: 구분(예금·주식·채권·부동산·합계) — 금액(원)
- 세부 목록:

| 구분 | 종별 | 평가액(원) | 비고 |
|---|---|---|---|
| 예금 | 정기예금 | | ＊금융기관명, 계좌번호, 상품명 기재 |
| 주식 | 소계 / 비상장 / 상장 | | ＊금융기관명, 계좌번호, 상품명 기재 |
| 채권 | 소계 / 국공채 / 중금채 / 회사채 / 보험 | | ＊금융기관명, 계좌번호, 상품명 기재 |
| 부동산 | 소계 / 토지 / 건물 | | ＊건물, 임야 등 종별로 구분하고, 종별 면적, 주소 등 기재 |
| 합계 | | | |

**작성방법·주의사항**:
- ※ 붙임(필수 제출) 보유 재산 종별 증빙서류 — 예금잔액증명서, 채권잔고증명서, 주식보유증명서, 부동산 등기부등본 등.
- ※ 부동산·주식·채권 등의 경우 감가상각비·공정가치 등의 평가기준을 반영하지 않은 **취득 시 장부가액**을 기재(기본재산: 단, 재평가를 실시하여 주무관청으로부터 재산목록 변경 허가를 받은 경우 현재 정관의 "별지목록 2 현재의 기본재산 목록"의 금액 기재 / 보통재산: 재평가를 실시한 경우 평가액 반영 가능).
- ※ 기타 재산이 있는 경우 행을 추가하여 작성.

### 서식 12 — 목적사업비 지급명세서 (별표 5)

**용도**: 장학금·연구비 등 목적사업비의 수혜자별 지급 실적 보고.

**템플릿**:
1. 장학금 지급실적: 번호 / 학교 / 학년 / 성명 / 장학금(원) / 비고 — 예시: ○○○대학교, 2, 홍길동, 1,000,000 — 합계
2. 연구비·교육기관 지원실적: 번호 / 대상 / 인원 / 성명 / 지원금(원) / 연구과제 — 예시: ○○대학원 사회학과(박사과정), 2, 김갑동, 1,000,000, "4차산업시대에 예상되는 병리현상과 대책" — 합계

**작성방법·주의사항**: ※ 행이 부족한 경우 추가하여 작성.

### 서식 13 — 공익법인 사업현황 (별표 6)

**용도**: 장학(학술, 교화)법인의 사업 실적·계획, 재산현황·세금납부 내역, 지역별·학교별 장학금 지급 실적을 보고.

**템플릿**:
1. 장학(학술, 교화)법인 현황 (단위: 명/천원): 법인명 — 사업(장학금 인원·지급액 / 연구비 / 기타목적사업비 / 운영비 / 합계) × 수입금내역(예금이자 / 주식배당 / 부동산임대 / 수익사업 / 기타 / 합계), 실적·계획 행 구분
2. 재산현황 및 세금납부 내역 (단위: 명/천원): 기본재산(현금·주식·채권·부동산·기타·소계)·보통재산(동일)·총합계 × 세금납부내역(법인세·재산세·취득세·등록세·부가세·합계), 실적·계획 행 구분
3. 지역별·학교별 장학금 지급 실적 및 계획 (단위: 명/천원): 학교별(초등학교~대학원·유학생·기타·합계) × 지역별(서울·지방·합계) × 실적/계획, 각 인원·지급액

### 서식 14 — 기부금 사용 내역서 (별표 7)

**용도**: 당해·이전 회계연도 기부금의 접수→승인·허가→집행 흐름과 차액 사용계획 보고.

**템플릿**: (단위: 원)

| 구분 | ① 접수 내용 (접수기간·금액·기부자·목적) | ② 승인·허가 내용 (승인(허가)일·금액·내역) | ③ 집행 내용 (집행일·금액·내역) | 비고 |
|---|---|---|---|---|
| 당해 회계연도 | 예시: 25.1. / 5,000,000 / 홍길동 외 3인 / 정관상 목적사업 | 25.3.10. / 5,000,000 / 장학금 | 25.6.20. / 5,000,000 / 장학금 | |
| 당해 회계연도 | 예시: 25.3. / 100,000,000 / 이순신 / 기본재산 편입 | 25.8.20. / 100,000,000 / 기본재산 증자허가 | 25.8.20. / 100,000,000 / 등기 완료 | |
| 당해 회계연도 | 예시: 25.12. / 5,000,000 / 장길산 외 8인 | | | 미집행 |

| 이전 회계연도 | (동일 구조로 기재) | | | |

**작성방법·주의사항**:
- ① 접수내용: 월별 기부금 접수 총액, 기부자 ○○○ 외 0명, 기부 목적 등을 기재

- ③ 집행내용: 실제 사용일(재산 증자 허가의 경우 정관 변경 등기 완료일)과 집행 총액 기재

- 차액 발생 시 차액 발생 사유 및 승인·허가 계획 등 기재
- 이전 회계연도 기부금: 당해 회계연도 이전에 접수되었으나 아직 승인·집행되지 않은 기부금이 있는 경우에만 기재(작성 방법은 당해 회계연도와 동일)
