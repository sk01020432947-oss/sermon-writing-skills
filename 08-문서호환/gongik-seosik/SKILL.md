## 2. 작업 절차

1. **업무 판별** 후 해당 reference 파일을 읽는다. reference의 "절차 개요·체크리스트"로 사용자의 상황(사단/재단, 신규/변경 등)을 먼저 확인한다.
2. **필요 정보 수집**: 템플릿의 `{플레이스홀더}` 중 사용자가 아직 주지 않은 항목을 한 번에 모아 질문한다(법인명, 대표자, 소재지, 회계연도, 재산 표시, 임원 명단 등). 낱개로 여러 번 묻지 않는다.
3. **서식 작성**: 사용자의 원자료를 reference의 템플릿·작성방법에 맞춰 채운다.
   - 해당 업무에 필요한 **서식 세트 전체**를 순서대로 작성한다(공문 → 사유서 → 내역서 → 회의록 순 등).
   - 사용자가 특정 서식 하나만 원하면 그것만 작성한다.
4. **검토 안내**: 완성본 뒤에 ① 구비서류 체크리스트(빠진 첨부물 표시), ② 제출 기한·처리 흐름, ③ 지침서의 주의사항(☞)을 요약해 붙인다.
5. **파일 출력**: 기본은 마크다운. 요청 시 .docx(워드)·.hwpx로 변환한다(hwpx는 mohwp/kordoc 도구 사용).

## 3. 공통 작성 규칙

- **문체**: 개조식(－, ○, □ 계층 구조). 지침서의 계층 기호 체계(□ 대분류 → ○ 세부 → － 상세)를 유지한다.
- **날짜**: `2026. 7. 29.` 형식(연. 월. 일. 뒤 마침표). 상대 날짜("다음 주")는 절대 날짜로 환산한다.
- **날인 표시**: 서명·날인 위치는 `(인)`으로 유지하고, 인감증명서 첨부·간인 요구는 체크리스트에 명시한다.
- **금액**: 천원 단위 표가 많다 — 템플릿의 단위 표기를 따르고 합계 검산을 한다.
- **모르는 값은 비워둔다**: 사용자가 주지 않은 사실(등기부 내용, 감정평가액 등)을 추정으로 채우지 않는다. `{미기재 — ○○ 확인 필요}`로 남기고 질문 목록에 올린다.
- **법적 한계 고지**: 산출물 끝에 "본 서식은 2026 실무지침서(2025.12.1. 기준) 기반이며, 제출 전 관할 교육청(교육지원청) 담당자 확인 및 국가법령정보센터(law.go.kr) 최신 법령 확인이 필요합니다"를 1회 붙인다.
