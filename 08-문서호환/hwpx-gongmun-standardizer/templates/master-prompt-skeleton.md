# {{기관명}} {{문서유형}} 글쓰기 마스터 프롬프트 (v1 초안)

근거 자료: {{샘플1}}, {{샘플2}}{{, 샘플3}} — 이 문서들의 문장·구조 규칙을 역추출. 완성된 .md는 HWPX 템플릿 스킬 입력으로 그대로 쓴다.

## 0. 이 프롬프트의 목적
새 {{문서유형}}을 작성할 때 아래 구조·문체 규칙을 그대로 따르면 샘플과 동일한 완성도의 초안이 나온다. 빈칸 `{{ }}`만 채우면 된다.

## 1. 표지 구성
```
「{{사업명}}」
{{공고 유형: 육성 지원사업 공고 / 선정 공고 / 시행계획 통보}}
{{공고일자: YYYY. M. D.}}
{{주관기관 로고 · 기관명}}
```
- 사업명은 낫표(「」)로 감싼다. 날짜는 `YYYY. M. D.` 형식(월/일 앞자리 0 없음).

## 2. 목차 구성 (장 개수 {{6~8}}개)
표준 장 순서: Ⅰ. 공고 개요 → Ⅱ. 사업 목적 → Ⅲ. 지원 개요 → Ⅳ. 신청 접수 → Ⅴ. 선정 평가 → Ⅵ. 선정 결과 발표 → Ⅶ. 유의사항 → 붙임
- 공통 반복(규칙): {{…}}  / 변화(선택): {{…}}

## 3. 본문 구성
- 장 제목(Ⅰ.) 바로 아래 **거버닝 문장 1개**(서술형, 한 문장).
- 절은 □ → ○ → - 3단 개조식. 4단 이상 금지.
- 문장 끝은 명사형/개조식("~지원", "~실시"), 서술형은 거버닝 문장에만.

## 4. 표 규칙
- 항목명 셀 가운데 정렬, 값 셀 왼쪽 정렬, 숫자 오른쪽 정렬. 단위는 헤더에 표기.

## 5. 붙임
- 본문과 분리해 "붙임 1. …" 형식, 끝에 "끝."
