# 프롬프트 모음 (영상 원문 기반, 슬롯만 치환)

## P1 · 글쓰기 마스터 프롬프트 역추출
```
업로드한 {{기관명}} {{문서유형}} 샘플 {{N}}건(PDF)을 비교 분석하고, 규칙을 추출해서
「글쓰기 마스터 프롬프트.md」 초안을 작성해줘.
반드시 포함: ① 문서 구조 대조(공통 반복=규칙, 변화=선택 사항) ② 문체 규칙(서술형/개조식, 불릿 체계 □→○→-, 금지 표현, 유지 표현) ③ 슬롯화(반복 패턴=고정 템플릿, 변수={{슬롯}}).
출력 구성: 0. 목적 / 1. 표지 구성 / 2. 목차 구성(장 개수 범위) / 3. 본문 구성(장·절·거버닝 문장) / 4. 표 규칙 / 5. 붙임 / 6. 날짜·기관·직인 표기 / 7. 금지·유지 사항.
```

## P2 · 프롬프트 검증 (다른 주제로 초안)
```
{{새 주제}} 내용으로, 지금 만든 글쓰기 마스터 프롬프트.md를 적용해서 샘플 초안.md를 작성해줘.
표지 → 목차 → 개요 → 목적 순서와 장 깊이가 원본 샘플과 같은지 스스로 대조표를 붙여줘.
```

## P3 · HWPX 템플릿 스킬(서식 지침) 생성
```
첨부한 {{기관명}} 공문 HWPX와 같은 문서의 PDF를 함께 분석해서, 이 기관 공문 서식을 표준화하는 HWPX 생성 스킬 지침(TEMPLATE-SPEC.md)을 만들어줘.
HWPX에서는 서식 규칙(charPr/paraPr/표 구조/secPr)을, PDF에서는 시각적 완성 상태를 읽어.
추출 항목: 판형·여백·머리글·바닥글·페이지 번호 / 장 표기(로마숫자+제목 별도 문단) / 절 3단 계층(□→○→-) / 거버닝 문장 위치 / 표 안 항목명·값 정렬 / 붙임 별도 섹션 / 폰트·크기·굵기·들여쓰기·행간·자간 표 / 로고 위치.
문서마다 서식이 다르면 다수결 + 최신 문서 우선으로 표준안을 제안하고 근거를 적어줘.
```

## P4 · 적용
```
[새 공문 내용.md]를 글쓰기 마스터 프롬프트.md 규칙으로 초안을 완성한 뒤,
{{기관명}} HWPX 템플릿 스킬을 적용해서 .hwpx로 만들어줘. 목차의 페이지 번호는 내가 알려주는 값으로 넣어: {{목차 번호}}.
```

## 자주 겪는 오류 → 처방
| 증상 | 원인 | 처방 |
|---|---|---|
| 한글에서 열자마자 깨짐 | 2020 이하 버전 | 한글 2024 이상에서 확인 |
| 목차 페이지 번호가 비어 있음 | 한글이 목차 필드 미인식 | 텍스트 목차로 수동 입력 |
| 초안이 자꾸 구조를 이탈 | 프롬프트 검증(P2) 생략 | 다른 주제로 P2 반복 후 규칙 보강 |
| 토큰 급증 | 마스터 프롬프트 단계에 HWPX 첨부 | 1단계는 PDF만 |
| 로고 깨짐 | 저해상도 캡처 | SVG/.ai 원본 → 고해상 PNG |
