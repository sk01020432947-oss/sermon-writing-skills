# HWPX 공문 표준화 파이프라인 (역추출 → 지침 → 적용)

> 출처: 우석진, 「클로드.ai 공공기관 아래한글 .hwpx 공문서 표준화 생성 반자동화 워크플로우」 (youtube.com/watch?v=0u5lqk0Vn5g)
> 핵심 철학: **완전 자동화보다 반자동화가 품질이 높다.** 사람이 확인하는 지점(한글 2024 검수, 목차 번호, 로고)을 남긴다.

## 두 산출물의 역할 분리 (혼동 금지)

| 산출물 | 답하는 질문 | 입력 | 저장 위치 |
|---|---|---|---|
| `글쓰기-마스터-프롬프트.md` | **무슨 내용을 어떤 순서·문체로** 쓰는가 | 공문 PDF 2~3건 (HWPX 불필요 — 토큰 낭비) | 작업 폴더 `standards/` |
| `TEMPLATE-SPEC.md` (기관 서식 스킬) | 완성된 내용을 **어떤 구성·서식으로 렌더링**하는가 | 같은 공문의 HWPX + PDF 쌍 (HWPX=규칙, PDF=시각 결과) | 작업 폴더 `standards/` + `hwpx` 스킬 호출 시 참조 |

## 실행 순서

### 0단계 · 입력 확인
- 샘플 공문 2건 이상인지 확인한다. 1건이면 "공통/변화 구분이 불가능하니 최소 2건"을 요청한다.
- 결과물은 `.hwpx`만. `.hwp` 요청은 `hwpx` 스킬 규칙대로 거부한다.
- 기관명·문서 유형(공고문/결과보고/계획보고/공문/사업계획서)·판형(A4 세로/가로)을 확정한다. 사용자가 이미 말했으면 묻지 않는다.

### 1단계 · 역추출 → `글쓰기-마스터-프롬프트.md`
`references/prompts.md`의 **P1**을 실행한다. 세 가지 연산을 반드시 수행한다.
1. **문서 구조 대조** — 샘플 간 공통 반복 → 규칙, 변화 → 선택 사항(슬롯).
2. **문체 규칙 연산** — 서술형/개조식 구분, 불릿 체계(□→○→- 3단), 금지 표현, 유지 표현.
3. **슬롯화** — 반복 패턴은 고정 템플릿, 변수는 `{{슬롯}}`으로 지정.
`templates/master-prompt-skeleton.md` 골격을 채워 저장한다. 표지·목차·본문(장/절/거버닝 문장)·표·붙임·날짜/기관 표기 규칙이 모두 들어가야 한다.

### 2단계 · 프롬프트 검증 (HWPX 전에 md에서 완성)
다른 주제로 **P2**를 실행해 `초안.md`를 만든다. 표지→목차→개요→목적 흐름이 원본과 같은 깊이인지 대조한다.
- 어긋나면 마스터 프롬프트를 고치고 재생성한다. **HWPX 단계로 넘기기 전에 내용은 md에서 100% 완성**한다. 스킬은 레이아웃만 담당해야 되돌아오는 비용이 없다.

### 3단계 · 서식 역추출 → `TEMPLATE-SPEC.md`
HWPX + PDF 쌍으로 **P3**을 실행한다. 표준화가 안 된 기관이면 여러 문서를 분석해 **표준안을 새로 제안**한다. 추출 항목:
- 판형·여백·머리글/바닥글·페이지 번호 위치
- 장 표기(Ⅰ/Ⅱ/Ⅲ + 제목 별도 문단), 절 3단 계층(□→○→-), 거버닝 문장 위치, 붙임 분리 섹션
- 폰트/크기/굵기/들여쓰기/행간/자간 표 (아래 기본값을 출발점으로, 실제 문서 값으로 덮어쓴다)

| 원본 패턴 | 표준 스타일 | 서식(출발값) |
|---|---|---|
| Ⅰ~Ⅵ 로마숫자+제목 | 장제목 | 맑은고딕 16pt bold, 가운데정렬 |
| □ | 개조식1 | 11pt bold, 들여쓰기 0mm |
| ○ | 개조식2 | 10.5pt, 들여쓰기 5mm |
| - | 개조식3 | 10.5pt, 들여쓰기 10mm |
| * / ※ | 설명 | 9.5pt 회색, 들여쓰기 15mm |
| 표 헤더/셀 | 표제목/표본문 | 10pt bold / 10pt |

`templates/template-spec-skeleton.md`를 채워 저장한다.

### 4단계 · 렌더링 & 검증 루프 (반자동)
1. `hwpx` 스킬을 호출해 `TEMPLATE-SPEC.md` + `초안.md`로 샘플 `.hwpx`를 만든다 (로컬이면 `gonmun` 템플릿 + `build_hwpx.py`, 검증은 `validate.py --layout`, `gonmun_lint.py`).
2. 사용자에게 **한글 2024 이상**에서 열어 확인하라고 안내한다. 클로드 아티팩트는 hwpx 미리보기가 안 되고, 2020 이하 버전은 깨짐이 잦다.
3. 사용자가 보고한 수정사항 → `TEMPLATE-SPEC.md` 수정 → 재생성. 원하는 결과가 나올 때까지 반복한다.

### 5단계 · 마감 (수동 항목 — 자동화하지 않는다)
- **목차 페이지 번호**: 한글이 클로드가 만든 목차 필드를 인식하지 못한다. 페이지가 적으면 사용자가 순서/번호를 알려주고, 수십 쪽이면 완성 PDF를 올려 번호를 매긴 **텍스트 목차**로 다시 쓴다.
- **로고**: SVG 또는 일러스트레이터 `.ai` 원본을 받아 고해상도 PNG로 변환해 삽입한다.
- 서식·규칙·레이아웃 최종 체크 후 `TEMPLATE-SPEC.md`에 버전과 날짜를 적는다.

### 적용 모드 (지침이 이미 있을 때)
`standards/글쓰기-마스터-프롬프트.md`와 `standards/TEMPLATE-SPEC.md`가 있으면 **P4** 순서로 간다: 새 공문 내용 → 마스터 프롬프트 적용 → md 완성 → `hwpx` 스킬 적용 → 목차 번호 수정 → 완성.
claude.ai 웹에서 쓰려면 `TEMPLATE-SPEC.md`를 SKILL.md로 감싸 zip으로 만들고 **설정 > 사용자 지정 > 추가 > 스킬 업로드**로 등록하라고 안내한다.
